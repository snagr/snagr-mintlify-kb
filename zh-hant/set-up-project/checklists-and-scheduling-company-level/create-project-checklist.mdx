<Note>
### <img src="/images/direct/1562237868694-519791-101_Warning-512.png" alt="519791 101 Warning 512" width="27" /> 這是一個公司管理區域的功能。
</Note>

_對於工程項目檢查清單，您只需在公司管理區域為清單添加名稱。 其餘部分(第2部分)則在項目級別添加。_

<img src="/images/direct/1562572722755-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

點擊左側目錄中公司檢查模板 ＞ "**工程項目檢查清單**" ＞ "**創建新****檢查清單**"

<img src="/images/direct/1562576268134-Admin_Website_Tra.002.jpeg" alt="Admin Website Tra.002" />

填寫清單名稱和清單名稱縮寫，然後單擊“**創建****檢查清單**”

<img src="/images/direct/1562666548802-1562666548802.jpeg" alt="1562666548802" />

您也可單擊“**編輯**”已有工程項目檢查清單進行編輯。

<img src="/images/direct/1562666613820-1562666613820.jpeg" alt="1562666613820" />

編輯後按"**儲存變更"**以確定。
