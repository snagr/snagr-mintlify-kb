#### 工程階段檢查

可以添加標準工程階段檢查來監控每個位置的進度。

例如：項目中的標準房間總是需要幾個步驟才能完成。

然後，您可以監控每個位置的進度。  
每個項目您可以設置完成百分比。

要使用項目的工程階段檢查，您需要先將它們匯入到特定位置。

點擊“匯入/匯出CS計劃”

選擇要匯入的計劃。這是在[公司管理區域添加](/zh-hant/set-up-project/checklists-and-scheduling-company-level/create-construction-stages)的，需在項目層面進行微調。

並選擇要添加此計劃的圖紙和/或位置類型。

然後點擊“**匯出模板**”。

它會要求您將文件保存到您的電腦。保存文件並將其打開。

它將顯示您匯出的計劃的詳細信息以及一些額外信息。

A列顯示位置ID，  
B是位置的外部參考，  
C列是檢查縮寫（應該全部相同），  
D列顯示圖紙標題，  
E列顯示位置名稱。這些列保持不變。  
您想要更改的項目是F列和G列。

您可以在此處定義要添加的計劃的開始日期和結束日期。默認設置為今天+公司級別的日程表中的日期。  
如果需要請更改日期。  
如果您的房間較大，需要的時間是普通房間的兩倍，您可以通過設置更晚的結束日期來延長計劃時間。

如果要排除特定位置，也可以刪除一個或多個位置。

如果您準備好了，請再次保存文件。

點擊“**重新匯入模板**”。

選擇剛剛保存的文件，然後單擊“匯入項目”。

任何錯誤都會以紅色顯示。在最後一欄中，您將看到錯誤的原因。如果表格全部為綠色，則可以匯入。為此，請點擊網格上方的“**匯入項目**”。

要查看計劃的詳細信息，請轉到階段的主頁面。

選擇您要查看的計劃，如果需要，請選擇圖紙。單擊“**查看圖紙**”。在頁面底部的網格中，您將看到所有計劃。

您可以在網格中查看常規信息，例如完成百分比。
