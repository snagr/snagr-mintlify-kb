添加項目時，管理員會為該項目添加一些基本信息。  
您可以在創建項目後編輯大部分數據，例如合約編號、默認語言、項目聯繫人信息、標誌、客戶用戶作為團隊協作，每日電郵發送時間等等。

<img src="/images/direct/1562219749982-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

登錄項目，

轉到目錄中的項目管理，再到“**項目設定**”。

在這裡，您可以看到項目的一般信息

<img src="/images/direct/1562219864721-Admin_Website_Tra.002.jpeg" alt="Admin Website Tra.002" />

 如果有需要，可以更改信息。

要儲存更改，請點擊頁面底部的“**更新項目設置**”以確定。
