登錄公司管理區域

您將看到“主要設置”頁面

<img src="/images/direct/1562046850528-1562046850528.jpeg" alt="1562046850528" />

在這裡，您可以看到公司名稱，網址和默認語言。

可以更改名稱和默認語言。 點擊“更新設置”以保存更改。

<img src="/images/direct/1562046253572-Admin_Website_Tra.003.jpeg" alt="Admin Website Tra.003" />

在下方，您將找到公司商標(標誌)設置。  
除非在您在項目級別再次更改以覆蓋此標誌，否則這些標誌將用於所有項目中。

要更改標誌，請選擇要上載的文件。 <img src="/images/direct/1531994672198-exclamation-mark.png" alt="exclamation mark" width="27" />_注意檔案尺寸大小_

點擊"更新標誌"以保存。
