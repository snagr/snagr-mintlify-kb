title: "如何編輯現有的圖紙？"
---

您隨時可以更改和編輯圖紙。

有幾件事您可以於圖紙上編輯：

要更改**圖紙**，請單擊選擇文件並上傳另一個圖紙以替換現有圖紙。

要更改裝置上顯示的圖紙**標題**，網頁和報告，請編輯圖紙標題。

要更改圖紙在網絡和裝置上的所有圖紙的下拉列表中顯示的**數字排序**，請更改排序順序（其他排序將根據此更改來自動更新）。

要更改編輯所屬的**圖紙集**。

要使此圖紙成為**首頁圖紙**，請勾選首頁圖紙的複選框。

要更改圖紙引用的**主圖紙**（例如：重複的房間計劃），請在連接到圖紙上進行編輯。

要**旋轉**圖紙，請單擊旋轉按鈕。它會將圖紙順時針旋轉90度。如果要將圖紙旋轉180度，請單擊該按鈕兩次。對於逆時針90度，點擊三次按鈕。

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> 如果您希望更改所顯示的圖紙，最好先下載原始圖紙並將其保存起來，以便在出現問題時返回原點。通過點擊“下載”來儲存。

<img src="/images/uploads/129423-exclamation-mark.png" alt="exclamation mark" width="20" /> 如果已經在編輯圖紙上發生了問題，請注意，當您進行任何更改時，圖紙的位置和比例需要與原件完全相同。否則，以前添加的問題將出現在查看圖紙上，並且不會再出現在正確的位置。如有必要，請在修改圖紙之前諮詢SnagR代表。
