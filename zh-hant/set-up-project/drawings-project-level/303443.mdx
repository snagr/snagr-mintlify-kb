選擇**圖紙集導航**意味著分配一個圖紙集來放置這些導航圖。 通常會創建一個名為"導航"的圖紙集來存儲這些自動生成的圖紙。

**如何只有特定的圖紙集？**

如不是要自動生成所有導航計劃，請選擇**自動生成獨立圖紙導航**。
