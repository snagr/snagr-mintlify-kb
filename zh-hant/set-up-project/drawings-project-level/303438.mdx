title: "建立重複單位的最快方法是什麼？"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **網頁版**

如果房間/單位類型會重複，最簡單的設置方法是使用重複圖紙。

在這個例子中，住宅建築在每個樓層都有一組相同的典型單元。

為了快速設置，計劃將是：

1.上傳所有典型佈局圖

2.為所有佈局圖設置位置

3.重複圖紙

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> 請注意，您要在重複繪圖之前設置位置，因為在這種情況下，位置也可以重複。

在您上傳圖紙並設置好位置之後，您可以重複圖紙：

<img src="/images/direct/1520418577410-Admin_Website_Tra.024.jpeg" alt="Admin Website Tra.024" />

<img src="/images/direct/1520419231714-Admin_Website_Tra2.001.jpeg" alt="Admin Website Tra2.001" />

在這個例子中，"A"將根據圖紙 Unit A 創建。留意旁邊產生位置的複選框已勾選，這意味著它也複製從Unit A到"A"的位置。

每次最多可以重複10個圖紙。

在您點擊上傳圖紙之前，請檢查您是否為這些重複的圖紙選擇了圖紙集。在這個例子中，圖紙"A"將落在圖紙集Construction下。在任何情況下，您都可以通過編輯現有圖紙進行更改。

<img src="/images/direct/1520419252636-Admin_Website_Tra2.002.jpeg" alt="Admin Website Tra2.002" />

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> 重複圖紙不僅使設置更容易，而且還節省了設備的存儲空間。例如，如果您的典型佈局計劃總共需要3 MB，無論您重複繪製多少次，重複的圖紙和一般的圖紙將總共保持3 MB，因為重複圖紙背後的機制僅指向主圖紙。
