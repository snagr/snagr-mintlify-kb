---
title: "如何管理電子郵件通知？"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **電腦版**

要為自己編輯訂閱，請轉至我的電子郵件通知。 點擊編輯，或者點擊取消訂閱，將自己從其他人為您設置的訂閱或自己設置的訂閱中刪除。

<img src="/images/direct/1520497282363-Admin_Website_Tra.061.jpeg" alt="Admin Website Tra.061" />

要編輯所有人的訂閱，請轉到“項目管理”&gt;“電子郵件通知”。 單擊編輯進行更改，或者單擊刪除以刪除整個訂閱。

<img src="/images/direct/1520497483675-Admin_Website_Tra.060.jpeg" alt="Admin Website Tra.060" />
