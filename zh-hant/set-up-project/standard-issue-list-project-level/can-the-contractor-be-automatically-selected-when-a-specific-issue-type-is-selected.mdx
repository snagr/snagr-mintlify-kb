---
title: "選擇特定缺陷類型時，是否可以自動選擇承辦商？"
---

SnagR 能夠把缺陷類別/類型 與 承辦商/組 接鏈在一起。

每種缺陷類型都可以設定為自動選定於項目中的特定承辦商組。以便用戶添加缺陷時，不再需要自選該分派於的承包商。

項目管理員可以充分利用此功能節省用戶從長列表中選擇承辦商的時間，並避免在缺陷記錄過程中出錯。

<img src="/images/direct/1554786731372-1554786731372.png" alt="1554786731372" width="26" /> **網頁**

<img src="/images/direct/1557379977025-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

轉到 "項目管理" &gt; "缺陷庫"

<img src="/images/direct/1557380026735-Admin_Website_Tra.002.jpeg" alt="Admin Website Tra.002" />

搜尋要為 承辦商/組 分配的 缺陷類別/類型

點擊 "添加/編輯承辦商”

<img src="/images/direct/1557380046764-Admin_Website_Tra.003.jpeg" alt="Admin Website Tra.003" />

選擇您要分配給所選缺陷類別/缺陷類型的承辦商，然後點擊 “Save”

_注意：您可以在此處從項目承包商列表中選擇多個承辦商。_  
_例如，如果您從項目承辦商列表中選擇2個承辦商，則在缺陷記錄過程中，可供選擇的項目將僅限於這兩個承辦商，而不是完整的項目承辦商列表__。_

<img src="/images/direct/1557380062926-Admin_Website_Tra.004.jpeg" alt="Admin Website Tra.004" />

承辦商被分配到缺陷類別下的缺陷類型。

完成！
