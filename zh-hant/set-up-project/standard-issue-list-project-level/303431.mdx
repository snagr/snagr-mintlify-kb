---
title: "添加缺陷時，我無法看到缺陷列表。 怎麼了？"
---

在公司管理區域上添加缺陷列表後，默認情況下它未在項目級別啟用，因此不要忘記在項目級別啟用它。

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **網頁版**

進入項目管理 &gt; 缺陷庫, 選擇**管理缺陷類型。**

<img src="/images/direct/1520414853609-Admin_Website_Tra.105.jpeg" alt="Admin Website Tra.105" />

然後，在彈出窗口中，選中您希望啟用的缺陷類別，然後點擊更新缺陷類別。

<img src="/images/direct/1520414877091-Admin_Website_Tra.106.jpeg" alt="Admin Website Tra.106" />
