---
title: "如何添加承辦商？"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **電腦版**

承辦(包)商名單是您想要提出意見的承包商。如果承包商未被添加到系統中，您將無法為他們分配缺陷。

**需要什麼？**

**承包商名稱和縮寫**

當您分配缺陷並生成缺陷報告時，會顯示承包商名稱。縮寫用作登錄的承包商用戶名，並且也顯示在圖釘上（以便您了解誰負責圖紙上的缺陷）。

**電子郵件地址**（可選）

每個承包商帳戶最多可以儲存3個電子郵件地址。如果您希望承包商接收來自SnagR的報告通知，請設置電子郵件地址。

**如何添加承包商/組？**

當一切準備就緒後，點擊添加承包商。

<img src="/images/direct/1520492346766-Admin_Website_Tra.037.jpeg" alt="Admin Website Tra.037" />

**檢查是否已經在公司中添加了承包商**

在繼續添加新承包商之前，最好查看一下現有的承辦商列表，看看您想添加的承包商是否已經存在。

<img src="/images/direct/1520492457788-Admin_Website_Tra.040.jpeg" alt="Admin Website Tra.040" />

<img src="/images/direct/1520492474108-Admin_Website_Tra.041.jpeg" alt="Admin Website Tra.041" />

如果承包商已經存在，請勾選並點擊添加承辦商。

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="25" /> 使用Ctrl + F（Windows）或Command + F（Mac）執行搜索。

**添加一個新的承包商**

如果承包商是公司的全新帳戶，請單擊添加新承辦商。

<img src="/images/direct/1520492715898-Admin_Website_Tra.038.jpeg" alt="Admin Website Tra.038" />

<img src="/images/direct/1520492775045-Admin_Website_Tra.039.jpeg" alt="Admin Website Tra.039" />

<img src="/images/uploads/127504-Pencil_Emoji.png" alt="Pencil Emoji" width="20" /> 什麼是**啟用**？  
如果您希望承辦商能訪問系統，請選中啟用。如果您不想承辦商再次訪問，請取消勾選該框。那時他們將無法登錄系統。請注意承辦商可以被禁用，但不能被刪除。這是為了保護項目數據，使得不管情況如何，與承辦商有關的任何數據都不會消失。  
<img src="/images/uploads/127504-Pencil_Emoji.png" alt="Pencil Emoji" width="20" /> 什麼是**可以寄送電郵嗎？**  
如果您希望承辦商接收來自SnagR的電子郵件通知，請勾選該框。

**想要更快建立？使用Excel匯出和重新載入承辦商**

匯出和重新載入功能是一種為承辦商帳戶高效設置電子郵件地址的工具。

在匯出承辦商清單之前，承辦商帳戶應該已經添加到項目中。如上所述，您可以從公司現有列表中添加承包商，或者快速創建帳戶，而無需添加電子郵件聯繫人。

當承辦商列表完成後，點擊匯出/重新載入承辦商。

<img src="/images/direct/1520493045511-Admin_Website_Tra.042.jpeg" alt="Admin Website Tra.042" />

<img src="/images/direct/1520493092842-Admin_Website_Tra.043.jpeg" alt="Admin Website Tra.043" />

<img src="/images/direct/1520493249616-Admin_Website_Tra.044.jpeg" alt="Admin Website Tra.044" />

<img src="/images/uploads/127504-Pencil_Emoji.png" alt="Pencil Emoji" width="20" /> 確保電子表格名稱為ContractorDetails，以便匯入與數據庫表匹配。承包商名稱和縮寫必須保持一致，以便可以匹配到承包商帳戶的電子郵件地址更新。

<img src="/images/direct/1520493428248-Admin_Website_Tra.045.jpeg" alt="Admin Website Tra.045" />

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="25" /> 如果匯入提示錯誤（紅色項目），請檢查您的電子表格並確保電子郵件地址不包含空格。您可能還需確保您在電子表格中未有創建多餘的帳戶或更新承包商名稱和縮寫。

當所有項目顯示為綠色時，單擊匯入分包商即可繼續。
