---
title: "如何設置自訂報告的權限？"
---

只有**項目管理員**能夠設置自訂報告的權限。

**怎麼設置？**

**<img src="/images/direct/1556270588373-1556270588373.png" alt="1556270588373" width="21" /> 網頁版**

<img src="/images/direct/1561625315093-131.001.jpeg" alt="131.001" />

1.轉到**項目管理** &gt; **Custom Reports**

2.如果您的項目有多個自訂報告，請從下拉列表中選擇您要管理訪問權限的報告。

3.選擇要管理訪問權限的用戶，並通過

<img src="/images/direct/1561625617951-1561625617951.jpeg" alt="1561625617951" />

 及

<img src="/images/direct/1561625595842-1561625595842.jpeg" alt="1561625595842" />

 將用戶移動到 "現有用戶" 或 “Assigned Users”。

_請注意，系統不會自動將新添加的用戶設置為能夠查看自訂報告。 在創建新帳戶時，不要忘記為新用戶提供訪問權限。_
