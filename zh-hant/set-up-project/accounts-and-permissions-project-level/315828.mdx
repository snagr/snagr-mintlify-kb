---
title: "如何設置權限？（表格）"
---

權限設置是一個十分重要的話題，因為它不僅確保了數據安全，而且還為您的項目團隊**制定了一個明確的流程**，這是推出任何系統的**關鍵成功因素**，SnagR也不例外。  
當每個人都知道**什麼**人需要於**什麼**時候做**什麼**事情，人們將會更容易採用新系統。

**用戶帳戶**

在用戶頁面上，轉到編輯權限。

<img src="/images/direct/1520493807437-Admin_Website_Tra.067.jpeg" alt="Admin Website Tra.067" />

在**編輯用戶檢查項目**時，權限選項如下：

沒有權限

只讀

可編輯（注意：意味著用戶不能添加檢查表格，只能在現有檢查表格中編輯。）

可添加

可結束（可結速）（注意：意味著它不允許用戶在檢查表格再進行編輯）。

**可重開**（注意：表示它允許其他人再次在檢查表格上進行編輯。）

**可刪除**（注意：要能夠刪除檢查表格，用戶還需要成為管理員以[分配缺陷權限](/zh-hant/set-up-project/accounts-and-permissions-project-level/315824)。）

<img src="/images/direct/1520493917315-Admin_Website_Tra.068.jpeg" alt="Admin Website Tra.068" />

-------------------------------------------------------------

在**編輯用戶表格**時，權限選項如下：

沒有權限

只讀

可編輯（注意：編輯意味著用戶可以編輯表格，但是當"可更新用戶"更新表格項目時，"可編輯用戶"將不能再編輯該項目。）

可更新

可結束（可結速）

**可重開**（注意：表示它允許其他人再次在檢查表格上進行編輯。）

**可刪除**（注意：要能夠刪除檢查表格，用戶還需要成為管理員以[分配缺陷權限](/zh-hant/set-up-project/accounts-and-permissions-project-level/315824)。）

<img src="/images/direct/1520493935082-Admin_Website_Tra.069.jpeg" alt="Admin Website Tra.069" />

基於檢查表格是由一個或多個表格組成的模板，請在同時於**編輯用戶檢查項目**和**編輯用戶表格**中更新權限。。

對於批量更新，請使用頂部的**更新全部**功能。

**承包商表格權限**

在承辦商頁面上，轉到編輯&gt;編輯權限(Edit Permission)。

<img src="/images/direct/1520494289665-Admin_Website_Tra.070.jpeg" alt="Admin Website Tra.070" />

<img src="/images/direct/1520494310890-Admin_Website_Tra.071.jpeg" alt="Admin Website Tra.071" />

<img src="/images/direct/1520494354606-Admin_Website_Tra.072.jpeg" alt="Admin Website Tra.072" />

在**編輯檢查表格**時，權限選項如下所示：

沒有權限 No Access

只讀 Read Only

可編輯 Can Edit（注意：意味著用戶不能添加檢查表格，只能在現有檢查表格中編輯。）

可添加 Can Add

可結束 **Can Close**（注意：意味著它不允許用戶在檢查表格再進行編輯）。

**可重開 Can Reopen**（注意：表示它允許其他人再次在檢查表格上進行編輯。）

**~~可以刪除 Can Delete~~**（注意：分包商並不能刪除檢查表格，因為它們不能通過設定成為項目管理員。）

<img src="/images/direct/1526010613762-exclamation-mark.png" alt="exclamation mark" width="24" />注意：分包商帳戶只能看到他們**創建的檢查****表格**及**分配給他們的****檢查****表格**。他們看不到其他與他們無關的檢查表格。

要批量更新，請使用頂部的**更新全部**功能。
