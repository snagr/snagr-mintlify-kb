---
title: "如何發送密碼提醒？"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **網頁****版**

**用戶 (舊版本）**

要為個人用戶提醒密碼，請單擊發送密碼。

要為所有用戶提醒密碼，請單擊頁面底部的發送密碼提示電郵至所有用戶。

<img src="/images/direct/1520495475412-Admin_Website_Tra00.001.jpeg" alt="Admin Website Tra00.001" />

**用戶 (新版本）**

在新版本中，您只能向他們發送密碼重置電子郵件，而不是提醒密碼電子郵件。

要為個人用戶送密碼重置電子郵件，請單擊 Send。

要為所有用戶送密碼重置電子郵件，請單擊頁面底部的Remind all User Logins至所有用戶。

<img src="/images/direct/1561367569953-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

**承辦商**

要為個別承辦商提醒密碼，請單擊發送密碼。

要提醒所有承辦商的密碼，請單擊頁面底部的提示所有密碼。

<img src="/images/direct/1520495251737-Admin_Website_Tra.066.jpeg" alt="Admin Website Tra.066" />
