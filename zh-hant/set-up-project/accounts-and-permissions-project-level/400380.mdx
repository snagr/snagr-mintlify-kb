---
title: "如何批量編輯用戶角色權限/啟用用戶？"
---

批量編輯用戶角色權限/啟用用戶之前需要了解的事項：

- [缺陷權限](/zh-hant/set-up-project/accounts-and-permissions-project-level/315824)
- <img src="/images/direct/1556879590136-exclamation-mark.png" alt="exclamation mark" width="26" />用戶角色將直接影響用戶的缺陷和表格權限，不應在更新缺陷/表格權限後才更新用戶角色。
- <img src="/images/direct/1556878137919-1556878137919.png" alt="1556878137919" width="26" /> 什麼是**啟用****？** 如果您希望用戶訪問系統，請勾選啟用。 如果您不希望用戶再次登入，請取消勾選該框。 他們將無法登錄系統。 請注意，可以禁用用戶但無法刪除。 這是為了保護項目數據，以便用戶之前創建了任何缺陷及表格的記錄始終保留。

<img src="/images/direct/1561696728080-Admin_Website_Tra.008.jpeg" alt="Admin Website Tra.008" />

“項目管理 ”&gt; “用戶” &gt; “批量編輯用戶” ("Batch Edit Users")

<img src="/images/direct/1561698075070-Admin_Website_Tra.009.jpeg" alt="Admin Website Tra.009" />

選擇要編輯的用戶

<img src="/images/direct/1561698181750-Admin_Website_Tra.010.jpeg" alt="Admin Website Tra.010" />

您可以通過搜索關鍵字來選擇多個用戶。

<img src="/images/direct/1561698204592-Admin_Website_Tra.011.jpeg" alt="Admin Website Tra.011" />

勾選"Edit User(s) Roles" 以編輯用戶角色。

<img src="/images/direct/1561698240400-Admin_Website_Tra.012.jpeg" alt="Admin Website Tra.012" />

檢查"Enable / Disable selected User(s)?" 以啟用/禁用用戶。

<img src="/images/direct/1561698421342-Admin_Website_Tra.013.jpeg" alt="Admin Website Tra.013" />

"Save" 保存！
