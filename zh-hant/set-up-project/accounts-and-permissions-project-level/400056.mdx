[/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues](/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues)

- [表格權限](/zh-hant/set-up-project/accounts-and-permissions-project-level/315828)

準備好了嗎？

我們開始吧！

<img src="/images/direct/1561695381291-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

項目管理 &gt; 用戶 &gt; 批量編輯用戶權限（"Batch Edit User Permissions"）

<img src="/images/direct/1561695400846-Admin_Website_Tra.002.jpeg" alt="Admin Website Tra.002" />

選擇“用戶”以編輯權限

您可以通過搜索關鍵字來選擇多個用戶。

**選項1 - 加載權限（**load permissions）****

<img src="/images/direct/1561705946839-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

如果現有用戶擁有您要複制的權限。請選擇加載。

<img src="/images/direct/1561695441804-Admin_Website_Tra.004.jpeg" alt="Admin Website Tra.004" />

檢查每個類別的權限設定；

**選項2 - 編輯權限（****Edit permissions）**

<img src="/images/direct/1561695459420-Admin_Website_Tra.005.jpeg" alt="Admin Website Tra.005" />

如果不需要加載現有用戶權限(no existing user permissions loaded)，則必須為用戶於所需類別內編輯權限。

然後，

<img src="/images/direct/1561695493078-Admin_Website_Tra.006.jpeg" alt="Admin Website Tra.006" />

點擊“Update User(s) xxxxxxxx Only”以更新指定類別權限。

或

<img src="/images/direct/1561695512371-Admin_Website_Tra.007.jpeg" alt="Admin Website Tra.007" />

點擊 "Update All Permissions for all selected User(s)"以更新所選用戶的所有類別權限。
