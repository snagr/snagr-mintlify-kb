使用SnagR應用程式上的二維碼掃描器可非常有效地在建築物中找到您的確切位置。  
將[位置添加到項目](/zh-hant/set-up-project/drawings-project-level/303442)後，建立屬於位置的二維碼非常簡單。

點擊左側目錄中的“項目管理”

選擇下拉目錄中的條碼生成器 （QR code)

<img src="/images/direct/1561706943653-Admin_Website_Tra.001.jpeg" alt="Admin Website Tra.001" />

通過過濾位置來建立特定位置的二維碼，或者將這些選項留空，它將為所有位置生成二維碼。  
點擊"**建立多個條碼**"並等待彈出框。

<img src="/images/direct/1561708015029-Admin_Website_Tra.002.jpeg" alt="Admin Website Tra.002" />

將顯示所有選定位置的二維碼。

你可以將它們打印出來並在貼上每個位置。
