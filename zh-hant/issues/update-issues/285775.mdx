title: "如何更新缺陷？"
---

在[缺陷創建](/zh-hant/issues/add-issues/280571)之後，牽涉到多方人員來修改，簽署和關閉缺陷。這樣讓所有的有關人員參與其中就尤為重要。

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **移動設備**

當你嘗試要關閉缺陷，你有如下幾個選擇：

**快速關閉：**改變缺陷狀態，圖釘的顏色也會隨之改變。

**關閉並評論：**改變缺陷的狀態，並附以照片或者評論，圖釘的顏色也會隨之改變。

**<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="20" /> 誰**可以更新缺陷？

除了只讀用戶，所有的SnagR用戶和承包商都可以使用更新缺陷功能。

**如何**在網頁版更新缺陷

你可以在缺陷總覽或者查看圖紙界面更新缺陷。

**缺陷總覽**

直接將缺陷拖動到你想要的目標欄中。

<img src="/images/direct/1520321232699-Website-Issue-Mode_Tra.016.jpeg" alt="Website Issue Mode Tra.016" />

<img src="/images/direct/1520321304481-Website-Issue-Mode_Tra.017.jpeg" alt="Website Issue Mode Tra.017" />

**查看圖紙**

點擊關閉/修復來改變缺陷的狀態。

<img src="/images/direct/1520321322383-Website-Issue-Mode_Tra.018.jpeg" alt="Website Issue Mode Tra.018" />

根據你在系統內所預設的權限，你會相應地看到按鈕&lt;修復&gt;簽收&gt;&lt;關閉&gt;。
