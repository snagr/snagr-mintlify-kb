### **缺陷總覽**

總覽 ＞ 缺陷總覽

然後轉換列表模式到 "**大**"

<img src="/images/direct/1524475369044-Website-Issue-Mode_Tra.001.jpeg" alt="Website Issue Mode Tra.001" />

如有需要，請先利用搜尋索引以得縮小缺陷範圍。

<img src="/images/direct/1524475448039-Website-Issue-Mode_Tra.002.jpeg" alt="Website Issue Mode Tra.002" />

<img src="/images/direct/1524475621805-Website-Issue-Mode_Tra.003.jpeg" alt="Website Issue Mode Tra.003" />

得出結果後，按**批量編緝**。

<img src="/images/direct/1524478667689-Website-Issue-Mode_Tra.001.jpeg" alt="Website Issue Mode Tra.001" />

選取所有或逐一選取需要編緝之缺陷，然後按編緝

<img src="/images/direct/1524478719474-Website-Issue-Mode_Tra.002.jpeg" alt="Website Issue Mode Tra.002" />

<img src="/images/direct/1524478755915-Website-Issue-Mode_Tra.003.jpeg" alt="Website Issue Mode Tra.003" />

<img src="/images/direct/1524478954672-Website-Issue-Mode_Tra.004.jpeg" alt="Website Issue Mode Tra.004" />

完成！
