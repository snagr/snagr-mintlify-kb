If you have the "Show filter?" option switched on in the main menu, you will have a split screen in the app when you go to the drawings. If you turn off this settings then you can access these filter options by tapping the filter icon

**Applying a Filter:**

In Issue mode, at the bottom of the left hand panel there are seven filters.

The first filter is by Location. This shows a list of all of the locations on the drawing in which you are currently on.

This allows you to tap on certain locations to see a full list of the Issues linked to it. The number in brackets represents the number of Issues linked to that location. This number updates according to the combination of the other six filters that you apply. This makes it very easy to routinely inspect areas based on the Issues that you wish to see.

If you tap on the location name the location will be selected (appears in the middle of the screen in red) and will show a list of the issues that are linked to that location.

Tap on an issue in the list to view its details.

The other filters available are:

- Subcontractor/group
- Issues Library
- Status
- Due date
- Priority
- Owner

For Example: if you are interested only in the issues that you added that were a high priority, you can tick your name in the list of owners and tick High within the priority filter. (Note: you can select multiple options in each filter apart from due date)

At the top of each filter there is a search option. Here you can search for items in the list to speed up the filter process.

You can see how many filter options you have applied by the numbers in red circles on each filter item.

Once the filters are applied, tap the filter button  in the top right hand corner of the panel.

**Remove Filter:** If you want the filter to be undone, go to the filter and click the refresh button  at the top left of the pop up. All issues will show again.

These filters can be used both in Issue mode and in Inspection mode. If you are on inspection mode it shows you the number of inspections per location or the number per inspection.

On **Android** **device**, we can do it as this way

When you tap on the filter icon , the filter options appear.

On the far left you see a location icon. This list will show you all the locations on the current drawing.

In () you see the number of issues (or inspections) that are attached to the location. If you tap a location with issues (or inspections) it will show you the list of issues.

If you tap on a issue it will show you the details. To go back to the filter screen tap on the back button.

Next to the location icon you find the filters.

The filters you can use at the moment are:

- Contractor/group
- Issue Library
- Status
- Due date
- Priority
- Owner

At the top on the location/filter part you'll also a search option. Here you can search for items in the list that you have chosen.

So if you are interested in the issues you added with a high priority, you can tick your name in the list of owners and tick High at the priority tab. Then choose the filter icon on the top right of the screen. Only the issues that you added with high priority will show on the drawing. If you also want the urgent issues to show, also tick Urgent at the priority tab.

If you want the filter to be undone, go to the filter and click Reset on the top of the screen. All issues will show again.
