title: "Gibt es eine Versionsverwaltung in SnagR-Dokumenten?"
---

SnagR kann beim Speichern aller Dateiversionen helfen und zeigt dann den Verlauf aller Änderungen an, wenn Dateien und Zeichnungen geändert werden. Stellen Sie sicher, dass die Benutzer immer die neueste Version haben.

Wenn Sie beispielsweise eine neue Zeichnung haben, müssen Sie die alte ersetzen, damit die Leute nicht mehr auf die alte Zeichnung verweisen.

Laden Sie dazu die neue Zeichnung an denselben Speicherort im **Dokumentenablage** hoch. Wenn Sie dies tun, wird die alte Datei ersetzt. Sie können den Verlauf dieser Änderungen anzeigen (sowohl neue Uploads als auch Ersatz-Uploads).

Wenn die neue Datei einen anderen Namen als die Originaldatei hat und Sie dies nicht ändern möchten, können Sie einen zusätzlichen Ordner mit alten Revisionen erstellen und die Originaldatei darin ablegen.

Klicken Sie auf den Ordner, in dem die Datei oder Dateien abgelegt werden sollen, und klicken Sie auf **Hochladen**.

<img src="/images/direct/1525768637048-Document_Website.001.jpeg" alt="Document Website.001" />

Laden Sie eine Datei mit der Ziehmethode oder durch einen manuellen Upload hoch, in dem Sie die Datei auswählen.  
<img src="/images/direct/1525755968318-Red_Flag_Emoji.png" alt="Red Flag Emoji" width="23" />Achten Sie also darauf, dass das Original auch dann erhalten bleibt, wenn die von Ihnen hochgeladene Datei einen anderen Namen hat.

<img src="/images/direct/1525768652880-Document_Website.002.jpeg" alt="Document Website.002" />

<img src="/images/direct/1525768695539-Document_Website.003.jpeg" alt="Document Website.003" />

Klicken Sie auf die Datei und die Details werden im nebenstehenden Fenster angezeigt. Klicken Sie auf **Verlauf anzeigen**, um dies in der jeweiligen Datei anzuzeigen.

<img src="/images/direct/1525768750162-Document_Website.004.jpeg" alt="Document Website.004" />

Ein Verlauf aller Revisionen dieser Datei wird angezeigt. wann wurde es hinzugefügt und von wem. Jede Revision kann heruntergeladen und angezeigt werden, indem Sie auf das Symbol neben der Revision klicken.
