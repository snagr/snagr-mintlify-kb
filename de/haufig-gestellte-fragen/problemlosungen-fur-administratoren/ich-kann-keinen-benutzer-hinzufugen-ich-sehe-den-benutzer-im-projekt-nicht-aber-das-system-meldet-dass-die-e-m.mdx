---
title: "Ich kann keinen Benutzer hinzufügen. Ich sehe den Benutzer im Projekt nicht, aber das System meldet, dass die E-Mail-Adresse bereits existiert. Was ist los?"
---

Wenn Sie einem Projekt einen neuen Benutzer hinzufügen möchten und die Meldung erhalten, dass dieser Benutzer bereits vorhanden ist, besteht eine gute Chance, dass der Benutzer bereits in der Unternehmensdomäne vorhanden ist.

**Was kann ich tun**

Sobald Sie auf **Benutzer hinzufügen** klicken, wird eine Tabelle mit allen vorhandenen Benutzern im Unternehmen angezeigt. Wählen Sie die Benutzer aus der Liste aus und klicken Sie auf **Benutzer importieren**.

Bitte beachten Sie, dass die Anmeldedaten des E-Mail-Benutzers **automatisch überprüft** werden. Wenn der Benutzer nicht sofort per E-Mail benachrichtigt werden soll, deaktivieren Sie dieses Feld.

**Das ist eine lange Liste! Kann ich in der Liste nach Benutzern suchen?**

Natürlich können Sie die Felder Name und / oder E-Mail verwenden, um nach dem gesuchten Benutzer zu filtern. Darüber hinaus können Sie auch die Suchfunktion des Webbrowsers selbst verwenden. Strg + F (unter Windows) oder CMND + F (unter Mac).
