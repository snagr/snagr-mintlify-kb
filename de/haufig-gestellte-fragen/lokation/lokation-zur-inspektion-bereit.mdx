Sobald alle Aktionspunkte für den Abschluss des Projekts unterzeichnet wurden, kann der Status eines Lokation von "Aktiv" in "Bereit zur Inspektion" geändert werden. Dies ändert die Lokationenfarbe von blau nach gelb.

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

Um einen Lokation als Inspektionsbereit zu markieren, klicken Sie im Hauptmenü auf **Zeichnungsumgebung** und vergewissern Sie sich, dass Sie sich im Aktionspunktmodus befinden.

Navigieren Sie zu der Zeichnung, die den Lokation enthält, den Sie als "Zur Inspektion bereit" markieren möchten.

Klicken Sie auf den Lokation

Klicken Sie auf **Zur Inspektion bereit**.

Die Lokation wird dann gelb.

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **App**

Auf einem **iOS-Gerät** machen Sie das wie folgt:

<iframe src="https://player.vimeo.com/video/108713071" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

Drücken Sie auf die Lokation, die zur Überprüfung bereit ist.

Drücken Sie im angezeigten Popup-Fenster auf **Fertig f Inspektion**.

<img src="/images/direct/1547557379686-1547557379686.png" alt="1547557379686" />

Das Popup wird automatisch geschlossen und die Lokationefarbe wechselt von blau  nach gelb

Dies ist eine visuelle Hilfe, um festzustellen, ob der Lokation zur Überprüfung bereit ist.

Wiederholen Sie die ersten beiden Schritte, um den Lokation wieder als aktiv (blau) festzulegen.
