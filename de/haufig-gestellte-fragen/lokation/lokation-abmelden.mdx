Die Option Lokation abmelden im Hauptmenü gibt Ihnen einen Überblick über den Status aller Standorte.

Sie können nach Lokation oder nach Zeichnung filtern, es ist jedoch auch möglich, eine vollständige Liste aller Lokationen im Projekt anzuzeigen.

Wenn Sie auf **Daten anzeigen** klicken, werden diese im Raster unten auf der Seite angezeigt.

Sie können die Lokationemarkierung auf der Basis von Zeichnung, Position oder Position mit Details drucken.
