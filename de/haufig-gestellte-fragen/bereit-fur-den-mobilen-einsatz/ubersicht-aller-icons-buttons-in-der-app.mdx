Beim Einrichten eines Projekts sollten alle Zeichnungen über Navigationslinks verknüpft sein.

Durch Drücken eines dieser Symbole gelangen Sie zu einer anderen Zeichnung.

Sie können auch zwischen den Zeichnungen wechseln, indem Sie auf die Schaltfläche "Zeichnungen" am unteren Bildschirmrand klicken. .Sie erhalten dann eine Liste aller Zeichnungen, auch wenn diese über die Navigation nicht erreichbar sind.

Mit der Schaltfläche Zurück  im Menü kehren Sie zum vorherigen Schritt zurück und können so zur vorherigen Zeichnung zurückkehren.

Die Home-Schaltfläche  bringt Sie direkt zurück zur Hauptnavigationszeichnung.

**Menü**

Klicken Sie oben im Fenster auf die Menüschaltfläche, um das Menü anzuzeigen.

Das Menü enthält die folgenden Optionen:

- Benachrichtigungen - _Hier sehen Sie alle Benachrichtigungen, die Sie erhalten haben._
- Dashboard - _Hier sehen Sie das Inspektions-Dashboard mit allen Inspektionen des Projekts._
- Aktivitätsprotokoll - _Hier sehen Sie alle Aktivitäten im Projekt. Sie können auf die Elemente drücken, um den Aktionspunkt anzuzeigen._
- QRCode / BarCode - _Hier können Sie Codes scannen, um einen entsprechenden Lokation zu öffnen._
- Legende - _Hier sehen Sie eine Erklärung der in der App verwendeten Farben und Symbole. Für eine detailliertere Erklärung klicken Sie [hier](/nl/ga-van-start/startgids-hoe-ga-ik-met-actiepunten-om/wat-betekenen-de-verschillende-actiepunt-kleuren)._
- [/en/issues/update-issues/what-do-the-pin-colours-represent](/en/issues/update-issues/what-do-the-pin-colours-represent)Projekt synchronisieren - _Ermöglicht das Synchronisieren des Projekts mit der Webversion._
- Hilfe & Support - _Hier können Sie vom SnagR-Support gesendete Nachrichten posten und einen neuen Chat mit dem Support-Team starten._
- Abbrechen - _Schließt das Menü_
- Hauptmenü - _Rückkehr zum Hauptmenü._

Oben rechts auf dem Bildschirm sehen Sie zwei Symbole, zwischen denen Sie wechseln können. Dies betrifft den **Aktionspunktemodus**   und den **Inspektionsmodus**

Am unteren Bildschirmrand finden Sie eine Reihe von Symbolen. Das können Sie damit machen:

- Lokation [hinzufügen](/nl/project-opzetten/locaties-projectniveau/hoe-voeg-ik-locaties-toe-op-tekeningen) [/en/set-up-project/locations-project-level/how-to-set-up-locations-on-drawings](/en/set-up-project/locations-project-level/how-to-set-up-locations-on-drawings) - _Fügen Sie einen neuen Standort an einem gewünschten Standort hinzu._
- Filter [festlegen](/nl/actiepunten/actiepunten-vinden/kan-ik-actiepunten-op-tekeningen-filteren)  - _Sie können nach Subunternehmern, Standardaktionspunkten, Status, Enddatum, Priorität und Eigentümer filtern._
- Zeichnungsliste  - _Wählen Sie die Zeichnung aus, die Sie anzeigen möchten._
- Schaltfläche "Zurück"  _- Führt Sie zur zuvor geöffneten Zeichnung._
- Home-Schaltfläche  - _Kehrt zur Hauptnavigationszeichnung des Projekts zurück._
- [QR-Scanner](/nl/project-opzetten/locaties-projectniveau/hoe-genereer-ik-barcodes-qr-codes-voor-locaties)  - _Führt Sie zum Barcode- / QR-Code-Scanner._
- Dokumentenspeicher  - _Führt Sie zum Dokumentenspeicher._

**Lokationmenü**

Wenn Sie auf ein Standortsymbol drücken, zeigt die App ein Menü an. Nachfolgend finden Sie die Optionen dafür.

- Aktionspunkt hinzufügen - [_Wie füge ich einen Aktionspunkt hinzu_](/nl/ga-van-start/startgids-hoe-ga-ik-met-actiepunten-om/hoe-voeg-ik-een-actiepunt-toe)_?_
- Verknüpfte Punkte anzeigen - _Es werden nur die Aktionspunkte angezeigt, die mit diesem bestimmten Ort verknüpft sind._
- Dokumentenverwaltung - _Verknüpfen Sie Dokumente mit einem bestimmten Speicherort. Weitere Informationen zum Verknüpfen von Dokumenten mit Standorten finden Sie [hier](/nl/documenten/documenten-beheren/hoe-koppel-ik-documenten-aan-locaties)._
- Aktivitätenübersicht - _Zeigt die letzten Aktivitäten rund um diesen Lokation an._
- Bereit v Inspektion - _Wählen Sie diese Option, sobald ein Standort für die Inspektion bereit ist. Lesen Sie_ [_hier_](/it/faq/siti/location-ready-for-inspection) _mehr über Bereit v Inspektion._
- Lokation schließen - _Ein Lokation, der zur Überprüfung bereit ist, kann durch Anklicken geschlossen werden. Weitere Informationen zum Markieren eines Lokationen finden Sie_ [_hier_](/nl/veelgestelde-vragen/locaties/locatie-aftekenen)_._

**Navigation**

Beim Einrichten eines Projekts sollten alle Zeichnungen über Navigationslinks verknüpft sein.

Durch Drücken eines dieser Symbole gelangen Sie zu einer anderen Zeichnung.

Sie können auch zwischen den Zeichnungen wechseln, indem Sie oben auf dem Bildschirm auf die Schaltfläche "Zeichnungen" klicken . Wenn Sie einen Schritt zurückgehen möchten, können Sie die Android-Zurück-Taste am unteren Bildschirmrand drücken. Die zuvor geöffnete Zeichnung wird dann erneut geöffnet.
