---
title: "Können Aktionspunktberichte automatisch generiert werden?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Webseite**

In SnagR können Aktionspunktberichte automatisch über automatische Benachrichtigungen generiert werden. Sie können die im Bericht angezeigten Informationen selbst zusammenstellen. Der Zweck einer automatischen Benachrichtigung besteht darin, zu verhindern, dass Sie regelmäßig selbst Berichte erstellen müssen.

<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="25" /> **Wer** sieht diese automatischen Benachrichtigungen?

Nur Sie erhalten und sehen die E-Mails, die Sie abonniert haben. Als Administrator können Sie automatische Benachrichtigungen für andere Benutzer festlegen.

**Wie richte ich automatische Benachrichtigungen für Aktionspunkte ein?**

In diesem Beispiel werden Aktionspunkte für Abonnements eingerichtet. Wir werden täglich einen Bericht über alle Aktionspunkte erstellen, die an diesem Tag erstellt wurden.

Gehen Sie zu Meine automatischen Benachrichtigungen&gt; Automatische Aktionspunktbenachrichtigungen und klicken Sie auf Neue automatische Aktionspunktbenachrichtigung.

<img src="/images/uploads/129600-Admin_Website.054.jpeg" alt="Admin Website.054" />

<img src="/images/uploads/129601-Admin_Website.055.jpeg" alt="Admin Website.055" />

Wählen Sie aus, welche Art von Benachrichtigungen Sie erhalten möchten: Direkt, Täglich, Wöchentlich oder Monatlich.

<img src="/images/uploads/129423-exclamation-mark.png" alt="exclamation mark" width="25" /> Eine direkte Benachrichtigung sendet eine separate E-Mail pro Werbepunkt, wenn sie die Kriterien Ihres Abonnements erfüllt und das Gerät synchronisiert ist. Dies macht direkte Benachrichtigungen ideal für Notfälle. Für einen allgemeinen Bericht ist ein Tagesabonnement viel besser geeignet, da nur eine E-Mail gesendet wird, einschließlich aller an diesem Tag hinzugefügten und aktualisierten Aktionselemente.

<img src="/images/uploads/129602-Admin_Website.056.jpeg" alt="Admin Website.056" />

Wenn Sie Täglich, Wöchentlich oder Monatlich auswählen, können Sie alle Aktionspunkte oder nur Aktionspunkte innerhalb einer bestimmten Anzahl von Tagen in den Bericht aufnehmen. In diesem Fall haben wir 1 Tag ausgewählt, da wir nur einen Bericht über Aktionspunkte wünschen, die an diesem Tag erstellt und aktualisiert wurden.

Wenn Sie einen Wochenbericht auswählen, können Sie den Tag angeben, an dem der Bericht gesendet werden soll.

<img src="/images/uploads/129603-Admin_Website.057.jpeg" alt="Admin Website.057" />

In diesem Fall haben wir alle Aktionspunktstatus ausgewählt. Dies bedeutet, dass der Bericht Aktionspunkte für alle oben genannten Status enthält.

**Wenn Sie weitere Filter für einen Bericht benötigen ...**

Bevor Sie auf Automatische Benachrichtigung erstellen (Optionale Filter überspringen) klicken, wählen Sie Filterbericht hinzufügen.

<img src="/images/uploads/129605-Admin_Website.058.jpeg" alt="Admin Website.058" />

<img src="/images/uploads/129604-Admin_Website.058.jpeg" alt="Admin Website.058" />

Sie können Filter basierend auf Aktionspunkttypen, Zeichnungen, Positionen, Benutzern, Priorität und den verbleibenden Tagen, bevor der Aktionspunkt behoben werden muss, hinzufügen.

Wenn Sie zufrieden sind, klicken Sie auf Automatische Benachrichtigung.
