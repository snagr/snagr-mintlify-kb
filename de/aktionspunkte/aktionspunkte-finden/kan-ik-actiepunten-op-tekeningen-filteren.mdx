Wenn Sie die **Filteroption** im Hauptmenü aktiviert haben, haben Sie in der App einen geteilten Bildschirm, sobald Sie zu den Zeichnungen gehen. Wenn Sie dies deaktiviert haben, können Sie die Filter auswählen, indem Sie auf das Filtersymbol klicken.

**Wenden Sie einen Filter an:**

Im Aktionspunktmodus gibt es am unteren Rand des Filterbereichs, der links angezeigt wird, 7 Filteroptionen.

Der erste Filter ist nach Lokation. Dieser Filter zeigt eine Liste aller Positionen der Zeichnung an, an denen Sie gerade arbeiten.

Auf diese Weise können Sie an verschiedenen Lokationen drucken, um eine vollständige Liste der mit dem Ort verknüpften Aktionspunkte anzuzeigen. Die Zahl hinter dem lokation steht für die Anzahl der verknüpften Aktionspunkte. Diese Anzahl ändert sich basierend auf allen anderen von Ihnen festgelegten Filtern. Dies macht es sehr einfach, Bereiche routinemäßig auf Aktionspunkte zu untersuchen, die Sie sehen möchten.

Wenn Sie auf den Lokationnamen drücken, wird der Lokation ausgewählt (wird in der Mitte des Bildschirms rot angezeigt) und eine Liste der mit dem Lokation verknüpften Aktionspunkte angezeigt.

Drücken Sie auf einen Aktionspunkt, um dessen Details anzuzeigen.

Die anderen verfügbaren Filter sind:

- Subunternehmer / Gruppe
- Standard-Aktionspunktliste
- Status
- Enddatum
- Priorität
- Besitzer

Beispiel: Wenn Sie nur an den Aktionspunkten interessiert sind, die Sie selbst mit hoher Priorität hinzugefügt haben, wählen Sie Ihren Namen als Eigentümerfilter und hoch im Prioritätsfilter. (Hinweis: Sie können mehrere Optionen pro Filter auswählen, jedoch nicht am Enddatum.)

Über jedem Filter befindet sich eine Suchoption. Hier können Sie nach Elementen in der Liste suchen, um den Filtervorgang zu beschleunigen.

Anhand der Zahl im roten Kreis für jeden Filter können Sie erkennen, wie viele Filteroptionen Sie angewendet haben.

Sobald die Filter eingestellt wurden, drücken Sie auf das Filtersymbol oben rechts im Filterfenster.

**Filter entfernen:** Wenn Sie einen Filter rückgängig machen möchten, gehen Sie zum Filter und klicken Sie auf das Aktualisierungssymbol oben links im Filterfenster.

Sie können diese Filter sowohl im Aktionspunktmodus als auch im Inspektionsmodus verwenden. Im Inspektionsmodus sehen Sie die Anzahl der Inspektionen pro Lokation oder die Anzahl der Formulare pro Inspektion.

Auf einem **Android-Gerät** sieht das so aus:

Wenn Sie auf das Filtersymbol klicken

<img src="/images/direct/1564132581208-1564132581207.jpeg" alt="1564132581207" />

 , wird das Filterfenster angezeigt.

Ganz links sehen Sie das Lokationsymbol. Diese Liste zeigt Ihnen alle Positionen in der aktuellen Zeichnung.

Hinter dem Lokation wird in Klammern die Anzahl der mit dem Standort verknüpften Aktionspunkte (oder Inspektionen) angezeigt. Wenn Sie auf einen Lokation mit verknüpften Aktionspunkten (oder Inspektionen) klicken, wird eine Liste dieser Aktionspunkte (oder Inspektionen) angezeigt.

Wenn Sie auf einen Aktionspunkt drücken, werden die Details angezeigt. Um zum Filter zurückzukehren, drücken Sie die Zurück-Taste.

Neben dem Lokationsymbol finden Sie die anderen Filter:

- Subunternehmer / Gruppe
- Standard-Aktionspunktliste
- Status
- Enddatum
- Priorität
- Besitzer

Unter den Filteroptionen gibt es eine Suchoption. Hier können Sie nach Elementen in der Liste suchen, um den Filtervorgang zu beschleunigen.

Wenn Sie nur an den Aktionspunkten interessiert sind, die Sie selbst mit hoher Priorität hinzugefügt haben, wählen Sie Ihren Namen als Eigentümerfilter und hoch im Prioritätsfilter. (Hinweis: Sie können mehrere Optionen pro Filter auswählen, jedoch nicht am Enddatum.)

**Filter entfernen:** Wenn Sie einen Filter rückgängig machen möchten, gehen Sie zum Filter und klicken Sie auf das Aktualisierungssymbol oben rechts im Filterfenster.
