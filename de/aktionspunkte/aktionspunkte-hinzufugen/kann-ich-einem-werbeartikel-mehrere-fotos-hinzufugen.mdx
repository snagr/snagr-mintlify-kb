---
title: "Kann ich einem Werbeartikel mehrere Fotos hinzufügen?"
---

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" />  **App**

<iframe src="https://player.vimeo.com/video/108708142" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

In einigen Fällen möchten Sie einer Werbeaktion mehrere Fotos hinzufügen. Es kann sich um ein Einzelbild oder eine Reihe von Fotos aus verschiedenen Blickwinkeln handeln.

Befolgen Sie einfach die folgenden Schritte:

<img src="/images/uploads/127098-Issue_Mode_Device.009.jpeg" alt="Issue Mode Device.009" />

<img src="/images/uploads/127099-Issue_Mode_Device.010.jpeg" alt="Issue Mode Device.010" />

<img src="/images/uploads/127100-Issue_Mode_Device.011.jpeg" alt="Issue Mode Device.011" />

Nachdem diese Fotos hinzugefügt wurden, können Sie sie finden, indem Sie auf **Verlauf anzeigen** klicken.

<img src="/images/uploads/127101-Issue_Mode_Device.012.jpeg" alt="Issue Mode Device.012" />

<img src="/images/uploads/127102-Issue_Mode_Device.013.jpeg" alt="Issue Mode Device.013" />

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Webseite**

Sie können einem Aktionspunkt auch über die Website über die **Zeichenumgebung** Fotos hinzufügen.

<img src="/images/uploads/123676-Website_Issue_Mode.003.jpeg" alt="Website Issue Mode.003" />
