---
title: "Wie kann ich einem Inspektionsformular ein Foto aus meiner Fotogalerie hinzufügen?"
---

In einem Inspektionsformular können Sie Fotos hinzufügen, indem Sie ein Foto aufnehmen oder ein Foto aus der Fotogalerie hochladen.

Standardmäßig wird die Kamerafunktion weitergeleitet, wenn Sie auf das Fotofeld drücken. Wenn Sie das Fotofeld gedrückt halten, wird die Option zum Hochladen aus der Fotogalerie angezeigt.
