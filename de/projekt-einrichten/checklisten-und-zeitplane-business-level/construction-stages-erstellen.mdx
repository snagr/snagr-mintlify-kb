Dies ist eine Funktionalität auf Unternehmensebene

**M****elden Sie sich auf Unternehmensebene an** und klicken Sie auf **Unternehmensinspektionen&gt;** **Construction Stages**.

Klicken Sie zum Importieren einer Bauphasenprüfung auf **Construction Stage** importieren.

Geben Sie den Namen und die Initialen für die Construction Stage Inspektion ein und klicken Sie auf Inspektion durchführen.

Laden Sie die Vorlage für die Prüfstufen herunter.

Geben Sie die Vorlage mit den gewünschten Informationen ein.

In Spalte A geben Sie die Aktivität ein (z. B. Stromaufbereitung).

In Spalte B tragen Sie den Beruf (zB Elektriker) ein.

In Spalte C geben Sie die Anzahl der Tage nach dem Start ein. Normalerweise ist dies 0 und Sie zählen die Anzahl der Tage für die nächste Aktivität. Es ist möglich, mehrere Aktivitäten an einem Tag durchzuführen.

In Spalte D geben Sie die Dauer der Aktivität ein (zum Beispiel 2 für die Anzahl der Tage).

In Spalte E können Sie eine Inspektion verknüpfen (zum Beispiel, wenn Sie ein Formular ausfüllen müssen, um den Fortschritt bis zu diesem Moment zu verfolgen).

Wenn Sie fertig sind, speichern Sie die Datei, damit Sie sie hochladen können.

Kehren Sie zur Website zurück und klicken Sie auf **Auswählen**, um die neu erstellte Datei auszuwählen und hochzuladen. Klicken Sie dann auf **Elemente importieren**.

In einem Raster werden dann die Elemente angezeigt, die Sie in die Vorlage eingegeben haben.

Wenn beim Import Fehler auftreten, werden diese im Raster angezeigt. Wenn Fehler auftreten, ändern Sie die Vorlage und laden Sie sie erneut hoch. Wenn alles in Ordnung ist, wird alles in Grün angezeigt.

Sie kehren dann zur Übersicht der soeben durchgeführten Construction Stages Inspektion zurück.

Hier können Sie die Phasen bearbeiten. Wenn Sie die Vorlage ausfüllen und später hochladen möchten, können Sie in die Bauphasen gehen und auf **Ansicht** klicken.

Importieren Sie dann **neue Construction Stages**.
