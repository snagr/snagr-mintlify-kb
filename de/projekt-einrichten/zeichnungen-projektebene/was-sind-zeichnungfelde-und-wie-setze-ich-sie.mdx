Manchmal möchten Sie sehr große Karten in einem Projekt verwenden, um zu navigieren (z. B. eine ganze Etage einer Wohnung). Wenn Sie diese Zeichnung jedoch zum Erstellen eines Berichts verwenden, wird die Karte auf das A4-Format skaliert. Dies bedeutet, dass alle platzierten Aktionspunktstifte auch viel kleiner sind.

Um dem abzuhelfen, haben Sie bei Zeichnungsfelder. Mit Zeichnungsfelder können Sie die Karte in verschiedene Rahmen für die Berichte unterteilen. Wenn Sie nach Bereichen in der Zeichnung filtern möchten, müssen Sie den Grundriss dennoch als Zeichnungen laden.

Aus Gründen der Übersichtlichkeit dienen Zeichnungsfelder nur dazu, die **Anzeige in Berichten zu verbessern**.

Wenn Sie alle gewünschten Zeichnungen im Projekt hochgeladen haben, gehen Sie zu **Projektverwaltung&gt; Zeichnungsfelder**.

<img src="/images/direct/1524732167294-Admin_Website.001.jpeg" alt="helpjuice production/uploads/upload/image/3577/direct/1524732167294 Admin Website.001" />

### **Felder hinzufügen**

Wählen Sie im Dropdown-Menü oben links auf dem Bildschirm die Zeichnung aus, für die Sie Zeichnungsfelder erstellen möchten.

<img src="/images/direct/1524732202382-Admin_Website.002.jpeg" alt="Admin Website.002" />

Wählen Sie oben auf dem Bildschirm aus, wie viele Boxen Sie aufnehmen möchten.

Klicken Sie einmal auf das Boxen-Symbol, um das Boxen-Fenster zu öffnen und auszuwählen, wie viele Boxen Sie verwenden möchten. Sie können die Felder durchgehen, um zu sehen, was Sie auswählen möchten, und einmal auf die gewünschte Anzahl von Felder klicken, um diese auszuwählen.

<img src="/images/direct/1524732323032-Admin_Website.003.jpeg" alt="Admin Website.003" />

<img src="/images/direct/1524732378197-Admin_Website.004.jpeg" alt="Admin Website.004" />

Die Anzahl der von Ihnen gewählten Felder wird dann auf der Zeichnung angezeigt.

<img src="/images/direct/1524732472254-Admin_Website.005.jpeg" alt="Admin Website.005" />

Sie können die Größe der Felder anpassen, indem Sie ihre Linien ziehen.

<img src="/images/direct/1524732780612-Admin_Website.006.jpeg" alt="Admin Website.006" />

### **Felder zusammenführen und trennen**

Wenn Sie die linke Maustaste gedrückt halten, können Sie mehrere Felder auswählen. Sobald Sie die linke Maustaste loslassen, wird die Auswahl aktiv und die Option Zusammenführen wird oben auf der Seite angezeigt.

Wenn Sie diese Option auswählen, werden die ausgewählten Kurse zu einem großen Kurs zusammengeführt.

<img src="/images/direct/1524733013706-Admin_Website.007.jpeg" alt="Admin Website.007" />

Wenn Sie die zusammengeführten Felder wieder trennen möchten, können Sie dies tun, indem Sie den Kurs auswählen und oben auf die Option **Teilen** klicken . Dies ist daher nur bei zusammengeführten Felder möglich.

Um das erstellte Felderlayout zu speichern, drücken Sie oben auf der Seite auf **Speichern**.

<img src="/images/direct/1524733054503-Admin_Website.008.jpeg" alt="Admin Website.008" />

Wählen Sie die erste Option **Zeichnungsfelder auf Übersicht anwenden** und klicken Sie auf **Speichern**.

<img src="/images/direct/1524733094156-Admin_Website.009.jpeg" alt="Admin Website.009" />

Wenn andere Zeichnungen dasselbe Layout aufweisen müssen, können Sie die Layoutfelder in diese Zeichnungen kopieren, indem Sie erneut auf **Speichern** klicken , und dann die zweite Option auswählen. Wählen Sie dann die Zeichnung aus, in die die Kästchen kopiert werden sollen (wenn Sie in mehrere Zeichnungen kopieren möchten, halten Sie die STRG- / Befehlstaste gedrückt und wählen Sie alle gewünschten Zeichnungen aus).

Um diese Felder für diese Zeichnungen zu aktivieren, drücken Sie erneut auf Speichern.

<img src="/images/direct/1524733569313-Admin_Website.010.jpeg" alt="Admin Website.010" />

### **Felder ändern oder entfernen**

Wenn Sie nach dem Erstellen eines Berichts mit den eingestellten Zeichnungsfelder nicht zufrieden sind, können Sie die Felder natürlich noch anpassen. Führen Sie einfach die obigen Schritte erneut aus, um die Felder zu erstellen.

Wenn Sie keine Themen mehr verwenden möchten, verwenden Sie nur einen Zeichenbereich brauchen.
