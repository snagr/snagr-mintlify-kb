**Generieren Sie Navigationslinks für alle Zeichnungssätze.**

In diesem Beispiel handelt es sich um ein Wohnprojekt mit mehreren Einheiten auf einer Etage. Die Zeichnungssätze werden pro Etage erstellt, z. B. 5F, 6F, 7F usw. Jeder Zeichnungssatz besteht aus dem Einheitenlayout, z. B. 5A, 5B, 5C, 5D usw.

Sie können diese Links automatisch generieren lassen:

<img src="/images/uploads/129348-Admin_Website.013.jpeg" alt="Admin Website.013" />

**Wie** mache ich das?

<img src="/images/uploads/129345-Admin_Website.010.jpeg" alt="Admin Website.010" />

<img src="/images/uploads/129346-Admin_Website.011.jpeg" alt="Admin Website.011" />

Navigationszeichnung auswählen Karte bedeutet, dass ein Zeichensatz zugewiesen werden muss, um diese Navigationszeichnungen zu platzieren. In der Regel wird ein Zeichensatz mit dem Namen Navigation erstellt, um diese automatisch generierten Zeichnungen zu speichern.

**Wie wäre es nur mit bestimmten Zeichnungen?**

Wählen Sie anstelle von "Alle Navigationspläne automatisch generieren" die Option "Navigationsplan für einzelnen Zeichnungsordner automatisch generieren".

<img src="/images/uploads/129347-Admin_Website.012.jpeg" alt="Admin Website.012" />

Wählen Sie zunächst die Zeichnung aus, für die Sie die Navigation automatisch einstellen möchten. Wählen Sie dann, wo Sie diese automatisch generierte Zeichnung speichern möchten.
