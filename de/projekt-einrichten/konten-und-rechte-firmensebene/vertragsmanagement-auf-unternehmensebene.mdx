**Sie müssen ein Unternehmensadministrator sein, um Benutzer- und Auftragnehmerregister verwalten zu können. Alle Projektadministratoren können jedoch die Register verwenden, um Benutzer / Auftragnehmer zu ihrem Projekt hinzuzufügen.**

Die wichtigsten Vorteile dieser Funktionalität sind:

- Jeder Benutzer hat ein Login, obwohl Sie unterschiedliche Rechte für unterschiedliche Projekte innerhalb des Unternehmens haben.
- Das Hinzufügen von Benutzern / Auftragnehmern zu Ihrem Projekt ist sehr schnell und einfach.
- Sie können für Auftragnehmer Analysen zu verschiedenen Projekten erstellen.
- Das Adressbuch kann durch eine Reihe von Importen aufgefüllt werden.

### Fügen Sie Auftragnehmer auf Unternehmensebene hinzu

**Melden Sie sich auf Unternehmensebene an.**

Gehen Sie zu **Company Registers&gt; Contractor Register**.

Die Liste der Auftragnehmer, die bereits im System vorhanden sind, wird im Raster angezeigt.

Sie können einen oder mehrere Auftragnehmer über die Importfunktion hinzufügen. Zuerst erklären wir die Hinzufügung eines einzelnen Auftragnehmers.

**Einzelunternehmer hinzufügen**

Klicken Sie über dem Raster auf **Auftragnehmer hinzufügen**.

Geben Sie den Namen und die Initialen ein und geben Sie an, ob der Auftragnehmer aktiviert werden muss.

Klicken Sie auf **Auftragnehmer hinzufügen**.

**Auftragnehmer importieren**

Mit der Importfunktion können Sie mehrere Auftragnehmer gleichzeitig importieren.

Klicken Sie oberhalb des Rasters auf **Neue Auftragnehmer importieren**.

Auf dem Importbildschirm sehen Sie einen Download-Link für eine Importvorlage, die Sie eingeben können.

Nachdem Sie die Datei ausgefüllt haben, können Sie sie speichern, um sie hochzuladen.

Klicken Sie dann auf **Auswählen**, wählen Sie die Datei aus und klicken Sie auf **Öffnen**.

Der Name der Datei wird dann im Textfeld angezeigt.

Klicken Sie auf **Auftragnehmer importieren**, um die Liste zu importieren.

Auf einer neuen Seite wird eine Liste der Auftragnehmer angezeigt, die in der hochgeladenen Datei enthalten waren.

Wenn etwas nicht stimmt, wird der Benutzer in einem roten Balken angezeigt und was nicht stimmt. Beispielsweise ist möglicherweise einer der Auftragnehmer bereits im System.

Sie können Auftragnehmer entfernen, die sich bereits im System befinden, indem Sie auf das Kreuz am Ende der Zeile klicken.

Sie können auch die Daten der Auftragnehmer auf dieser Seite ändern.

Wenn Sie mit der Liste der Benutzer zufrieden sind, klicken Sie auf **Benutzer importieren**, um sie hinzuzufügen.
