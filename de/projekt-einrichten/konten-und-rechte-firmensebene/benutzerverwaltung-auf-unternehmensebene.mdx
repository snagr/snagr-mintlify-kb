**Sie müssen ein Unternehmensadministrator sein, um Benutzer- und Auftragnehmerregister zu verwalten. Alle Projektadministratoren können jedoch die Register verwenden, um Benutzer / Auftragnehmer zu ihrem Projekt hinzuzufügen.**

Die wichtigsten Vorteile dieser Funktionalität sind:

- Jeder Benutzer hat ein Login, obwohl Sie unterschiedliche Rechte für unterschiedliche Projekte innerhalb des Unternehmens haben.
- Das Hinzufügen von Benutzern / Auftragnehmern zu Ihrem Projekt ist sehr schnell und einfach.
- Sie können für Auftragnehmer Analysen zu verschiedenen Projekten erstellen.
- Das Adressbuch kann durch eine Reihe von Importen aufgefüllt werden.

### Fügen Sie Benutzer auf Unternehmensebene hinzu

**Melden Sie sich auf Unternehmensebene an**

Gehen Sie zu **Unternehmensregister&gt; Benutzerregister**

Die Benutzer, die dem System bereits hinzugefügt wurden, werden in einem Raster angezeigt.

Sie können einen einzelnen Benutzer hinzufügen oder die Importfunktion verwenden. Zunächst wird das Hinzufügen eines einzelnen Benutzers erläutert.

**Einzelnen Benutzer hinzufügen**

Klicken Sie über dem Raster auf **Benutzer hinzufügen**.

Geben Sie den Benutzernamen, den Namen, die E-Mail-Adresse, das Passwort und die [Standardrechte](/de/projekt-einrichten/konten-und-rechte-projektebene/wie-setzen-sie-benutzerrechte-formulare) ein. Darüber hinaus geben Sie an, ob das Konto aktiviert ist, der Geschäftsadministrator und / oder der Kunde, indem Sie dies überprüfen.

[/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues](/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues)

Klicken Sie auf **Benutzer hinzufügen**

**Benutzer importieren**

Verwenden Sie die Importfunktion, um mehrere Benutzer gleichzeitig hinzuzufügen.

Klicken Sie oberhalb des Rasters mit allen Benutzern auf **Importieren**.

Auf dem Importbildschirm können Sie eine Vorlage herunterladen, die Sie eingeben können.

Wenn Sie fertig sind, speichern Sie die Datei.

Klicken Sie dann auf **Auswählen**, wählen Sie die Datei aus und klicken Sie auf **Öffnen**.

Der Name der Datei wird im Textfeld angezeigt.

Klicken Sie auf Benutzer importieren, um die Benutzer aus der Datei zu **importieren**.

Auf einer neuen Seite wird eine Liste der Benutzer angezeigt, die sich in der hochgeladenen Datei befunden haben.

Wenn etwas nicht stimmt, wird der Benutzer in einem roten Balken angezeigt und was nicht stimmt. Es ist beispielsweise möglich, dass sich einer der Benutzer bereits im System befindet oder dass eine E-Mail-Adresse falsch ist.

Sie können Benutzer, die sich bereits im System befinden, löschen, indem Sie auf das Kreuz am Ende der Zeile klicken.

Sie können auch die Daten der Benutzer auf dieser Seite ändern.

Wenn Sie die Anmeldedaten nicht sofort senden möchten, stellen Sie sicher, **dass das Kontrollkästchen Anmeldedaten für E-Mail-Benutzer nicht aktiviert ist**. Wenn Sie die Daten senden möchten, überprüfen Sie natürlich das Feld.

Wenn Sie mit der Liste der Benutzer zufrieden sind, klicken Sie auf **Benutzer importieren**, um sie hinzuzufügen.
