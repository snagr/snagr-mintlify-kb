title: "Wie richte ich Aktionspunktbenachrichtigungen für alle Benutzer ein?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Webseite**

In SnagR können Sie eine automatische Benachrichtigung zum Empfang von Informationen hinzufügen. Es gibt an, welche Informationen Sie automatisch senden / empfangen möchten. Diese Benachrichtigungen erstellen automatisierte Berichte per E-Mail, sodass dies nicht regelmäßig manuell erfolgen muss.

<img src="/images/uploads/137634-electric-light-bulb_1f4a1.png" alt="electric light bulb 1f4a1" width="25" /> **Tipp**: Automatische Benachrichtigungen sind für den Start eines Projekts unglaublich hilfreich. Es schafft eine Erinnerung und hält die Dinge in Bewegung.

<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="25" /> **Wer** kann Benachrichtigungen für alle festlegen?

Nur für Administratoren. Wenn Sie kein Manager sind, können Sie Benachrichtigungen nur für sich selbst vorbereiten. Klicken Sie [hier](/de/projekt-einrichten/benachrichtigungen-projektebene/wie-verwalte-ich-automatische-benachrichtigungen), um mehr zu erfahren.

**Wie richte ich Aktionspunktbenachrichtigungen ein?**

In diesem Beispiel bereiten wir eine gemeinsame Benachrichtigung vor. Wir erstellen täglich einen Bericht über alle Aktionspunkte, die an diesem Tag erstellt oder aktualisiert wurden.

Klicken Sie auf **Neue automatische Inspektionsbenachrichtigung**

<img src="/images/uploads/129578-Admin_Website.047.jpeg" alt="Admin Website.047" />

<img src="/images/uploads/129579-Admin_Website.048.jpeg" alt="Admin Website.048" />

Wählen Sie aus, welche Art von Benachrichtigung Sie erhalten möchten. Direkt, täglich, wöchentlich oder monatlich.

<img src="/images/uploads/129423-exclamation-mark.png" alt="exclamation mark" width="20" /> **Erinnerung**: Bei einer direkten Benachrichtigung wird eine E-Mail pro Aktionspunkt gesendet, die die Benachrichtigungsanforderungen erfüllt (sobald die App synchronisiert ist). Deshalb ist es üblich, dies nur für Notfall-Aktionspunkte festzulegen. Für einen allgemeinen Bericht ist ein täglicher Bericht eine viel bessere Option. Auf diese Weise wird eine E-Mail für alle Werbeartikel gesendet, die am selben Tag hinzugefügt oder aktualisiert wurden.

<img src="/images/uploads/129597-Admin_Website.049.jpeg" alt="Admin Website.049" />

Wenn Sie Täglich, Wöchentlich oder Monatlich auswählen, haben Sie die Wahl, ob dies für alle Aktionspunkte oder nur für die Aktionspunkte gilt, die innerhalb eines bestimmten Zeitraums aktualisiert wurden.

Wenn Sie einen Wochenbericht auswählen, können Sie auch angeben, an welchem Wochentag Sie ihn erhalten möchten.

<img src="/images/uploads/129581-Admin_Website.050.jpeg" alt="Admin Website.050" />

<img src="/images/uploads/137635-notebook-with-decorative-cover_1f4d4.png" alt="notebook with decorative cover 1f4d4" width="20" /> **Hinweis**: Benutzern wird ein Bericht angezeigt, der die Anforderungen des festgelegten Filters erfüllt. Auftragnehmern werden hingegen nur die ihnen zugewiesenen Aktionspunkte angezeigt.

<img src="/images/uploads/129583-Admin_Website.051.jpeg" alt="Admin Website.051" />

Eine tägliche Benachrichtigung ist jetzt eingestellt.

**Wenn Sie weitere Filter für den Bericht benötigen ...**

Bevor Sie auf Automatische Benachrichtigung erstellen klicken, wählen Sie **Filterbericht hinzufügen**.

<img src="/images/uploads/129584-Admin_Website.052.jpeg" alt="Admin Website.052" />

<img src="/images/uploads/129585-Admin_Website.053.jpeg" alt="Admin Website.053" />

Sie können Filter basierend auf Aktionspunkttyp, Zeichnungen, Positionen, Benutzern, Prioritäten und der Anzahl der Tage bis zum Enddatum hinzufügen.

Wenn Sie zufrieden sind, klicken Sie auf **Automatische Benachrichtigung**.
