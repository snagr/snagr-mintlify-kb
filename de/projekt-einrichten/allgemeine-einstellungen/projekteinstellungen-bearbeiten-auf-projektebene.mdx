Wenn ein Projekt hinzugefügt wird, werden auch einige Informationen für dieses Projekt hinzugefügt. Sie können die meisten dieser Informationen anpassen, nachdem das Projekt erstellt wurde.

Beispiele für Informationen, die angepasst werden können, sind: Vertragsnummer, Standardsprache, Projektkontaktinformationen, Logo, Client-Benutzereinstellungen, Benachrichtigungszeitpunkt usw.

Melden Sie sich beim Projekt an

Gehen Sie im Menü zur **Projektverwaltung**

Klicken Sie auf **Projekteinstellungen**

Hier sehen Sie die allgemeinen Informationen zum Projekt

Sie können die gewünschten Informationen ändern.

Um die Änderungen zu speichern, klicken Sie unten auf der Seite auf **Projekteinstellungen bearbeiten**.
