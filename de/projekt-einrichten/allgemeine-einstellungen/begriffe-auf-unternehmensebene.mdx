**Dies ist eine Funktionalität auf Unternehmensebene**

**Melden Sie sich auf Unternehmensebene an**

Klicken Sie im linken Menü auf **Begriffe**

Hier zeigt ein Raster alle Begriffe an, die Sie optional für Projekte verwenden können. Die Bedingungen können an Ihre eigenen Wünsche angepasst werden, um sie besser an ein Projekt anzupassen.

**Programm** ist eine Auswahl von Begriffen, um sie schnell mit einem Projekt verknüpfen zu können.

Wenn Sie beispielsweise die Projekte pro Stadt speichern möchten, können Sie **Div1** in einen Städtenamen ändern.

Klicken Sie zum Ändern der Begriffe auf das Stiftsymbol am Ende der Zeile

Ändern Sie den Namen und drücken Sie zum Speichern das blaue Häkchen oder zum Abbrechen das rote Stoppschild.

Unter dem Raster können Sie angeben, ob diese Bezeichnungen beim Erstellen eines neuen Projekts angezeigt werden sollen. Aktivieren Sie dazu die **Zeile Zusätzliche Felder anzeigen** wenn Sie ein neues Projekt erstellen.

Sie können hier auch angeben, dass es nicht möglich ist, Benutzer oder Auftragnehmer innerhalb des Projekts selbst hinzuzufügen. Aktivieren Sie dazu die **Regeln Benutzer aus Project Disable hinzufügen** und / oder **Auftragnehmer aus Project Disable hinzufügen**.
