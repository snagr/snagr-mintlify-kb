**Hinweis: Nach der Bestätigung wird die Inspektion endgültig entfernt. Dies wirkt sich auf alle zuvor hinzugefügten Prüfungen im System aus, die auf dieser Prüfvorlage basieren. Wir empfehlen, dass Sie sich zuerst an das SnagR-Support-Team wenden, bevor Sie diesen Vorgang ausführen, wenn es sich um eine Inspektionsvorlage handelt, die bereits verwendet wurde.**

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Webseite**

**Melden Sie sich zunächst auf Unternehmensebene an**. Nur Unternehmensmanager sehen diese Schaltfläche.

<img src="/images/direct/1521177204174-Admin_Website.001.jpeg" alt="Admin Website.001" />

Gehen Sie zu **Geschäftsinspektionen&gt; Inspektionen**.

Die Inspektionsseite wird angezeigt. Bereits erstellte Prüfungen werden hier angezeigt.

Klicken Sie auf das Stiftsymbol  in der Zeile der Inspektion, die Sie bearbeiten möchten.

Ein Popup mit den Details der Inspektion wird angezeigt.

Wenn Sie die gesamte Inspektion löschen möchten, klicken Sie auf **Löschen**.

Geben Sie **DELETE** in das Textfeld ein, wenn Sie sicher sind, dass Sie die Inspektion löschen möchten.
