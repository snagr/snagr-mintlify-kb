**Dies ist eine Funktionalität auf Unternehmensebene.**

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Webseite**

**Melden Sie sich zunächst auf Unternehmensebene an**. Nur Unternehmensmanager sehen diese Schaltfläche.

<img src="/images/direct/1521177204174-Admin_Website.001.jpeg" alt="Admin Website.001" />

Gehen Sie zu **Geschäftsinspektionen&gt; Inspektionen**.

Klicken Sie auf die Schaltfläche **Bearbeiten** für die Inspektion, die Sie ändern möchten.

Sie sehen die verschiedenen Formulare, die bei der Prüfung verwendet werden.

Um eine Formel zu löschen, klicken Sie auf die Schaltfläche **Löschen**.

Klicken Sie im Popup auf **Löschen**, wenn Sie sicher sind, dass Sie das Formular aus der Überprüfung entfernen möchten.
