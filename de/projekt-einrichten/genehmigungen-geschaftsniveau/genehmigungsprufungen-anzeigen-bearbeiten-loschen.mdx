Dies ist eine Funktionalität auf Unternehmensebene

Nach dem Erstellen kann es wünschenswert sein, ein Formular so anzupassen, dass es geringfügig anders reagiert. Zum Beispiel, wenn nicht mehr gewünscht wird, dass das Formular dauerhaft auf dem Gerät gespeichert wird. Dieses Stück erklärt, wie Sie dies tun können.

**Genehmigungsprüfungen bearbeiten**

Klicken Sie auf **Unternehmensinspektionen**

Klicken Sie im erweiterten Menü auf **Genehmigung**

Die Seite Inspektionen zulassen wird angezeigt. Alle bereits erstellten Inspektionen werden in der Tabelle angezeigt.

Um eine Inspektion zu bearbeiten, klicken Sie auf das Stiftsymbol  in der Inspektionszeile.

Ein Popup-Fenster mit den Details der Inspektion wird angezeigt.

Bearbeiten Sie alle Details, die Sie ändern möchten.

Klicken Sie auf **Speichern**, um die Änderungen zu speichern.

Wenn Sie die Inspektion löschen möchten, klicken Sie auf **Löschen.**

**Hinweis: Nach Bestätigung des Löschvorgangs ist dies dauerhaft. Das Löschen einer Inspektion hat Konsequenzen für alle zuvor durchgeführten Inspektionen. Wenden Sie sich zuerst an das SnagR-Support-Team, bevor Sie eine bereits verwendete Inspektion löschen.**

**Genehmigungsformular bearbeiten**

Gehen Sie zur Inspektionsgenehmigung und klicken Sie in der Zeile der Inspektion, in der sich die Genehmigung befindet, auf **Genehmigung** **bearbeiten**.

Daraufhin wird der Bildschirm **Inspektionsformular verwalten** geöffnet, in dem die verknüpften Formen der Inspektion gefunden werden.

Hier können Sie die Genehmigungsdetails ändern, indem Sie auf das Stiftsymbol klicken

Ein Popup-Fenster mit den Informationen, die Sie anschließend ändern können, wird angezeigt.

Um ein anderes Bild anzuzeigen, klicken Sie auf das Stiftsymbol und laden Sie das neue Bild hoch, das Sie verwenden möchten.

Wenn Sie dem Formular eine zusätzliche Seite hinzufügen möchten (z. B. eine Seite mit Fotoanhängen), klicken Sie auf **Neue Seite** und laden Sie den neuen Hintergrund für diese Seite hoch.

Wenn Sie zufrieden sind, klicken Sie auf **Speichern**, um die Änderungen zu speichern.
