Dies ist eine Funktionalität auf Unternehmensebene.

Sobald die Inspektion erstellt wurde ([Inspektionsgenehmigung hinzufügen](/de/projekt-einrichten/genehmigungen-geschaftsniveau/genehmigungsprufungen-hinzufugen)), fahren Sie mit der Erstellung Ihrer Genehmigung (en) fort.

Wenn Sie Ihre neue Inspektion hinzufügen, werden Sie feststellen, dass noch keine Formulare (Genehmigungen) hinzugefügt wurden.

Um eine neue Lizenz zu erstellen, klicken Sie auf **Formular erstellen**.

Um eine zuvor erstellte Genehmigung zu verwenden, klicken Sie auf **Formular hinzufügen**.

Geben Sie den Lizenznamen in das Feld **Formularname** ein. Dieser Name kann mit dem Inspektionsnamen identisch sein, wenn die Inspektion nur die Lizenz enthält.

Geben Sie den Lizenzcode in das Feld **Formularcode** ein (max. 6 alphabetische Zeichen).

Geben Sie die Berechtigungsbeschreibung in das Feld **Formularbeschreibung** ein. Diese wird in der App angezeigt, um den Benutzer darüber zu informieren, was erwartet wird (maximal 30 Zeichen).

Geben Sie im Feld **Seitenzahl** an, aus wie vielen Seiten die Genehmigung besteht.

Wenn die Genehmigung genehmigt oder verweigert werden kann, aktivieren Sie die Option **Hat Gut / Nicht erlaubt**? zu.

Wenn Sie mit der Genehmigung zufrieden sind, klicken Sie auf **Formular hinzufügen**.

Laden Sie das Bild jeder Seite der Genehmigung.

Klicken Sie auf **Formular hinzufügen**.

Die Lizenzseiten werden dann in den Formularassistenten geladen, um [Hotspots hinzuzufügen](/de/projekt-einrichten/formulare-unternehmensebene/wie-erstelle-ich-ein-digitales-formular).[/en/set-up-project/forms-company-level/how-do-i-digitalise-a-form](/en/set-up-project/forms-company-level/how-do-i-digitalise-a-form)
