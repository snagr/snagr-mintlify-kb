_Um eine Genehmigung hinzuzufügen, müssen Sie zuerst eine Inspektion erstellen. Die Details einer Inspektion können exakt mit denen der Lizenz selbst übereinstimmen (dies ist häufig der Fall, wenn die Inspektion nur aus der Lizenz besteht)._

Klicken Sie auf **Unternehmensinspektionen**

Klicken Sie im Dropdown-Menü auf **Genehmigungsprüfungen**

Die Seite Inspektionen zulassen wird angezeigt. Bereits erstellte Inspektionen werden in der Tabelle angezeigt.

**Um eine neue Inspektion hinzuzufügen, klicken Sie auf Genehmigungsprüfungen hinzufügen.**

Geben Sie den Inspektionsnamen ein (dies kann daher der Lizenzname sein).

Geben Sie einen Inspektionscode ein (max. 6 Buchstaben).

Wenn die Inspektion dauerhaft auf dem Gerät gespeichert werden soll, aktivieren Sie die Option Auf Gerät speichern? zu.

Wenn Sie möchten, dass die Inspektion nicht nur über die Website, sondern über ein Gerät hinzugefügt wird, aktivieren Sie die Option Kann dem Gerät hinzugefügt werden? zu.

Wenn Sie mit der Prüfung zufrieden sind, klicken Sie auf Speichern. Um eine Lizenz hinzuzufügen, gehen Sie zum Formular Hinzufügen und wählen Sie dort die [Genehmigungsprüfungen](/de/projekt-einrichten/genehmigungen-geschaftsniveau/genehmigungsformularseite-hinzufugen) aus.
