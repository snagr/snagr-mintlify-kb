Sie finden alle Inspektionen Ihres Projekts im Inspection Dashboard.

Klicken Sie im Menü der Website auf Dashboards und dann im Untermenü auf Inspection Dashboard.

Oben auf der Seite können Sie die Inspektion filtern nach; Was für (Inspektion), Wo (Zeichnung, Ort), Wann (Datum hinzugefügt) und Wer (hinzugefügt von), um die gewünschten Inspektionen zu finden.

Der Filter wird sofort hinzugefügt

Unter dem Filterbereich finden Sie die Liste der Inspektionen

Wenn Sie auf einen Inspektionstitel klicken, wird dieser sofort erweitert und die Inspektion wird in die verschiedenen Workflow-Ebenen unterteilt.

Sie können die Inspektion auf eine andere Workflow-Ebene ziehen, Kommentare hinzufügen und diese speichern.

Bei jeder Inspektion können Sie sie in der Zeichnung anzeigen, den Workflowverlauf anzeigen und die Inspektion selbst anzeigen
