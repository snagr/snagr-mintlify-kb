Willkommen bei SnagR! In diesem kurzen Artikel behandeln wir die Aktionspunkte und Inspektionen, auf die Sie in SnagR stoßen können und die sich auf Sie beziehen:

_1) Aktionspunkte (Aktionspunktwiederherstellung);_

_2) Inspektionen (Formulare und Genehmigungen hinzufügen)_

Bevor wir beginnen, ist es hilfreich, sich auf die Verwendung von SnagR vorzubereiten. Installieren Sie die SnagR-App aus dem Appstore oder dem Google Play Store. Führen Sie dann die folgenden Schritte im Video aus, um ein Projekt hinzuzufügen:

_Aktionspunkte (Wiederherstellen von Aktionspunkten)_

**Wie kann ich alle erstellten Aktionspunkte sehen?**

In der App gehen Sie zu Menü&gt; Dashboard. Hier sehen Sie eine Liste mit allen erstellten Aktionspunkten. Mehr dazu können Sie [hier](/de/fangen-sie-an/startanleitung-wie-gehe-ich-mit-aktionspunkten-um/wie-suche-ich-nach-aktionspunkten) lesen.

**Wie erstelle ich einen Aktionspunkt?**

Sie können einen Aktionspunkt sowohl in der App als auch auf der Website hinzufügen:

<iframe src="https://player.vimeo.com/video/108707758" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

Für eine Schritt-für-Schritt-Anleitung klicken Sie [hier](/de/fangen-sie-an/startanleitung-wie-gehe-ich-mit-aktionspunkten-um/wie-fuge-ich-einen-cue-point-hinzu).

**Wie schließe ich einen Aktionspunkt?**

Wenn Sie einen Aktionspunkt als erledigt platzieren, erhält das Projektteam normalerweise eine Benachrichtigung darüber:

<iframe src="https://player.vimeo.com/video/108712072" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

Für eine Schritt-für-Schritt-Anleitung klicken Sie [hier](/de/fangen-sie-an/startanleitung-wie-gehe-ich-mit-aktionspunkten-um/wie-aktualisiere-ich-einen-aktionspunkt).

Denken Sie daran, die App regelmäßig zu [synchronisieren](/de/haufig-gestellte-fragen/bereit-fur-den-mobilen-einsatz/warum-muss-ich-synchronisieren), damit Sie die aktuellsten Daten sehen.

**Wie erstelle ich einen Aktionspunktbericht?**

Gehen Sie auf der Website zu Aktionspunktberichte&gt; [Erweiterter Bericht](/de/fangen-sie-an/startanleitung-wie-gehe-ich-mit-aktionspunkten-um/wie-erstelle-ich-einen-aktionspunktbericht). Stellen Sie die gewünschten Filter ein und klicken Sie auf Print to PDF.

Dies ist die grundlegende Methode. Eine ausführlichere Erläuterung zum Erstellen von Aktionspunkten finden Sie [hier](/de/aktionspunkte/berichte-und-statistiken/projektzusammenfassung-was-sind-diese-roten-zahlen).

_Inspektionen (Formulare und Genehmigungen hinzufügen)_

**Wie kann ich ein Formular oder eine Genehmigung anzeigen?**

Sie können Formulare je nach Bedarf [über die Website](/de/fangen-sie-an/startanleitung-wie-fuge-ich-formulare-hinzu/wie-kann-ich-formulare-auf-der-website-ausfullen) oder [die mobile App](/de/fangen-sie-an/startanleitung-wie-fuge-ich-formulare-hinzu/wie-fulle-ich-mit-der-app-ein-formular-aus) anzeigen, hinzufügen oder entfernen. Denken Sie beim Hinzufügen oder Ändern eines Formulars oder einer Erlaubnis über die App daran, die App zu synchronisieren, damit diese Änderungen für alle sichtbar werden.

**Wie finde ich Formulare oder Genehmigungen?**

Stellen Sie bei Verwendung der App sicher, dass Sie sich [im Inspektionsmodus](/de/haufig-gestellte-fragen/allgemein/was-ist-der-aktionspunktmodus-und-der-inspektionsmodus) befinden, und gehen Sie zu Menü&gt; Dashboard. Hier sehen Sie eine Liste aller Ihnen zugeordneten Inspektionen. Weitere Informationen finden Sie [hier](/de/haufig-gestellte-fragen/allgemein/was-ist-der-aktionspunktmodus-und-der-inspektionsmodus).

Gehen Sie auf der Website zu Inspektionen&gt; Inspektionsfinder, wo Sie eine Inspektion finden, die auf verschiedenen Referenzen basiert. Denken Sie an den Namen, den Status, die ID usw.
