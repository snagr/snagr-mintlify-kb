---
title: "How to generate link to view inspection form?"
---

**<u>To view first form of the inspection</u>**

https://\{\{ProjectURL\}\}/inspection/#/\{\{**InspectionID**\}\}

**<u>To view specific form within the inspection</u>**

https://\{\{ProjectURL\}\}/inspection/#/\{\{**InspectionID**\}\}/\{\{**FormCode**\}\}

**<u>To view form at a specific revision</u>**

https://\{\{ProjectURL\}\}/inspection/#/\{\{**InspectionID**\}\}/\{\{**FormCode**\}\}/\{\{**Version**\}\}

First version will be 1, second will be 2, and so on.

If you would like to get the latest version, simply leave it empty, i.e. hit https://\{\{ProjectURL\}\}/inspection/#/\{\{**InspectionID**\}\}/\{\{**FormCode**\}\} and it will bring you to the latest version of the form code within the inspection.
