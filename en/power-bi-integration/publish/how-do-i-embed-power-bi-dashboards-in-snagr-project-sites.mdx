---
title: "How do I embed Power BI reports in SnagR project sites?"
---

Once you are happy with the report, click Publish on Power BI Desktop.

<img src="/images/direct/1567054285095-Power-BI-Integration_Website.003.jpeg" alt="Power BI Integration Website.003" />

Select the company workspace that this report should belong to, and publish the report.

<img src="/images/direct/1567054348945-Power-BI-Integration_Website.004.jpeg" alt="Power BI Integration Website.004" />

Once the report is published, go to [https://app.powerbi.com](https://app.powerbi.com), login with your account, and go to the specific workspace. Click on Reports, you should then see the report that you just published. Follow the steps below to share the report with [mark@snagr.co.uk](mailto:mark@snagr.co.uk). This is required if the report needs to be embedded within SnagR websites.

<img src="/images/direct/1567054370587-Power-BI-Integration_Website.005.jpeg" alt="Power BI Integration Website.005" />

Then, click into the report, at the web URL, copy the report ID. The report ID is the string that follows after /reports/

<img src="/images/direct/1567054569103-Power-BI-Integration_Website.006.jpeg" alt="helpjuice production/uploads/upload/image/3577/direct/1567054569103 Power BI Integration Website.006" />

Afterwards, login to the project sites where you wish to embed the Power BI report. Go to Project Administration &gt; KPI Dashboards.

<img src="/images/direct/1567054779941-Power-BI-Integration_Website.007.jpeg" alt="helpjuice production/uploads/upload/image/3577/direct/1567054779941 Power BI Integration Website.007" />

After you click + under KPI Dashboard, a pop up window should appear. Give a Report Title, and paste in the report ID. Click Save.

<img src="/images/direct/1567055054772-Power-BI-Integration_Website.008.jpeg" alt="Power BI Integration Website.008" />

You have already embedded the Power BI report into this project site!

Next you want to give users (including yourself) the permission to view the Power BI report.

<img src="/images/direct/1567055164674-Power-BI-Integration_Website.009.jpeg" alt="Power BI Integration Website.009" />

Last, you may want to go to Dashboard &gt; KPI Dashboard to make sure the embedded report loads.

<img src="/images/direct/1567067714800-Power-BI-Integration_Website.010.jpeg" alt="Power BI Integration Website.010" />
