---
title: "How do I get my API token?"
---

Once login to a SnagR website, add **/api-docs** at the end of the project URL.  
Example:

[https://demo40.snagr.com.hk/demo/api-docs](https://demo40.snagr.com.hk/demo/api-docs)

You should then see the following page.

<img src="/images/direct/1567049983928-Power-BI-Integration_Website.001.jpeg" alt="Power BI Integration Website.001" />

Example:

Your access token will be ObtF5MZDk%2fwrHPIukhk
