---
title: "Can I change the location/discipline of an inspection form?"
---

No, currently this is not enabled. Once you create an inspection form, the created person or the admin is unable to change the location of the inspection.

If the location is an important element, e.g. triggers read only text in the form, or triggers notification based on specific location, what you can do is to either delete the form, or leave it for others to edit.

Note once you delete the form, the ID or Inspection Type ID cannot be recovered since each ID is unique. It is also not possible to migrate content from one inspection form to another.

This feature (ability to change location of an inspection form) will be available in SnagR new version (version 5). Thank you in advance for your patience.
