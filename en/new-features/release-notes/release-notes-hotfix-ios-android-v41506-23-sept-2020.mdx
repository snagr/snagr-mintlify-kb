---
title: "Release Notes - Hotfix iOS / Android v4.150.6 (23-Sept-2020)"
---

- This hotfix further improves the offline login functionality so that if you logout you are still able to offline login but still using the more secure way. This will prevent very remote workers who are traveling completely offline from being caught out.
- There will be a further hotfix released later this week with some medium priority bug fixes and improvements, but we thought it better to release the offline login improvement immediately.
