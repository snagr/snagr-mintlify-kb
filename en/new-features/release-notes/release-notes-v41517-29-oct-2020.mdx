---
title: "Release Notes - v4.151.7 (29-Oct-2020)"
---

- Extended support for QRCode scanning. Scan a QRCode and if it matches the value of any field (QRCode, Text, TextArea, User / Sub-Contractor List etc..) then it will show all matching Inspection Forms in a list. If it matches a single Inspection form it will be opened immediately at speed. This feature is useful for MIC, Pre-cast concrete tracking & permit / field worker verification (by appending QRCode to a safety helmet for example).
