---
title: "Release Notes - Hotfix iOS / Android v4.151.0 (25-Sept-2020)"
---

- Hotfix for iOS / Android with some medium priority improvements:
  - Added ability when scanning a QRCode for an Inspection Form that if there are multiple matches it will display these in a searchable list. If there is a single match it will immediately open the form. (MIC use-cases)
  - Fix for some Android devices had an issue with downloading the project after the security update earlier in the week. This is now fixed.
