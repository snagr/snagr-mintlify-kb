---
title: "Release Notes - Hotfix iOS v4.155.2 / Android v4.155.4 (17-Nov-2021)"
---

This hotfix has the following improvements:

- Mobile databases are now generated when requested, this can take up to 1:30s on large projects to the wording has been improved when downloading a project for the first time.
- Small iOS glitch when viewing Document Repository was showing transparent
- Better error reporting if connection is lost during project download
- Android is now built against v30 (required by Google Play) this required a hotfix.
