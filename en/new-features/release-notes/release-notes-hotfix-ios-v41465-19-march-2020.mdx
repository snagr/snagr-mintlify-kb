---
title: "Release Notes - Hotfix iOS v4.146.5 (19-March-2020)"
---

This is a hotfix release. It was possible if you were trying to download many documents at the same time from the document repository to tap on the same document to download before it was added to the queue. This would cause the downloader module to crash and downloading to pause until the app was restarted.

This hotfix re-implements how documents are added to the queue and will filter out duplicates creating a more robust experience.
