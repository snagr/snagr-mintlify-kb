**Navigation**

During a project being set up, all of the drawings should have been linked together using a series of navigation links.

By tapping on one of these it will take the user to the linked drawing.

It is also possible to jump to a drawing from any other drawing even if they are not directly linked up using navigation links. To do this, tap the Drawings button  in the menu pane at the bottom of your screen and select the drawing you wish to jump to.

The Back button  in the menu pane will retrace your steps, opening the previously opened drawing.

The Home button  will revert the user directly back to the site home screen

**Menu**

Click on the menu buttom at the top of the screen to show the menu.

The menu contains the following options:

- Notifications - This button will show you the notifications that you received.
- Dashboard - This button will redirect you to the inspection dashboard with all the inspections within the project.
- Activity Log - The activity log shows all the activities in the project. You can click on the items to see the issue.
- Legend - Here you can find the explanation of the colours and the icons used in the app. [Interpreting Colours of Issues](/it/difetti/aggiorna-informazioni-difetto/what-do-the-pin-colours-represent)
- Help & Support - Here you can find the messages we sent about the system and you can start a new conversation with the SnagR support team to ask questions.
- Synchronise Project - You can sync the project by using this button. [_Synchronisation_](/it/faq/get-ready-on-mobile/what-does-synchronise-mean)
- Main Menu - This button wil redirect you to the main menu.

In the top right corner of the screen you will find the toggle button to switch between "issue mode" and "Inspection mode"

On the bottom of the screen you will find a couple of icons also. Explained from left to right:

- Add a [location](/en/set-up-project/locations-project-level/how-to-set-up-locations-on-drawings)
- [Filter](/en/issues/find-issues/filtering-issues-on-device)
- Drawing list  - Choose the plan that you need to show.
- Back arrow  - Will redirect you to the previous accessed plan
- Home button  - Will redirect you to the Project Plan (Main Plan of the project)
- [Barcode](/it/faq/get-ready-on-mobile/how-can-i-go-from-one-drawing-to-another)  - Will redirect you to the barcode scanner.
- Document Repository  - Will redirect you to the Document Repository.

**Location Menu**

If you tap on a location, the app will show you a menu. The options are explained below.

- Linked documents to this location  - _Link documents to the location that belong to a specific location. See_ _[How to link documents to locations?](/en/documents/manage-documents/how-to-link-documents-to-locations) for more information._
- Add an issue - see [How to add an issue?](/it/difetti/aggiungi-difetti/how-to-add-an-issue) for more information
- View Linked issues - _View linked issue will filter issues according to the selected location. Only issues attached to this location will be shown. To show all the issues, click on deselect location._
- View Activity - _Will show recent activities related to selected location._
- Ready For inspection - _Once a location is ready for inspection, click on the ready for inspection Button and the status of the room will change accordingly_. _See_ _[Location Ready for Inspection](/en/faq/locations/location-ready-for-inspection) for more information._
- Close / Handover - _A location that is ready for inspection can be closed by clicking on the Close / Handover button. See [LSO](/it/faq/siti/location-sign-off) for more information._

**Navigation**

During a project being set up, all of the drawings should have been linked together using a series of navigation links.

By tapping on one of these it will take the user to the linked drawing. Links placed in the top left hand corner generally navigate back a step or directly to the site plan.

It is also possible to jump to a drawing from any other drawing even if they are not directly linked up using navigation links. To do this, tap the Drawings button  in the menu pane at the bottom of your screen and select the drawing you wish to jump to.

The Android back button in the menu pane will retrace your steps, opening the previously opened drawing.

**Menu**

At the top of the screen you will see the following buttons from left to right:

- [Filter](/en/issues/find-issues/filtering-issues-on-device) - You can filter issues according to sub-contractors, standard issue, status, Due date, Priority and owner by choosing them and click filter.
- Drawings  - Choose the plan that you need to show.
- Mode button  - To toggle between "Issues mode" & "Inspection mode" [Inspection Mode vs Issues Mode](/it/faq/generale/what-is-issue-mode-and-form-mode)
- [QR Scan](/it/faq/get-ready-on-mobile/how-can-i-go-from-one-drawing-to-another) - Scan a QR code to go directly to that location.
- Menu button  - Click on the menu button to show the menu items (see below)

In the menu you will find the following options:

- Add [Location](/en/set-up-project/locations-project-level/how-to-set-up-locations-on-drawings)
- View Activity - View Activity will show all the recent activities recorded on SnagR.
- Help & Support - Here you can find the messages we sent about the system and you can start a new conversation with the SnagR support team to ask questions.
- Notifications - Notifications will show you all the events and actions that are related to the logged in user.
- Dashboards - Will show you the issues and inspections of the whole project in a searchable list.
- Legend - Here you find the explanation of the colors of the locations and pins [Interpreting Colours of Issues](/it/difetti/aggiorna-informazioni-difetto/what-do-the-pin-colours-represent).
- Document Repository - Here you can view the documents of the Document Repository of SnagR .
- Synchronise project - With this button you will send your recorded data to the central server and it will download new info [Synchronisation](/it/faq/get-ready-on-mobile/what-does-synchronise-mean).
- Main Menu - The main menu button wil redirect you to the main page

**Location Menu**

In the location menu you have the following options:

- Add issue ([How to add an issue?](/it/difetti/aggiungi-difetti/how-to-add-an-issue))
- View Linked issues. _View linked issue will filter issues according to the selected location. Only issues attached to this location will be show. To show all the issues , click on deselect location._
- Document Repository. _View the documents linked to the location. See [How to link documents to locations?](/en/documents/manage-documents/how-to-link-documents-to-locations) for more information._
- Ready For inspection. _Once a room is ready for inspection, click on the ready for inspection Button and the status of the room will change accordingly_. [Location Ready for Inspection](/en/faq/locations/location-ready-for-inspection)
- Close Location. _A room that is ready for inspection can be closed by clicking on the Close / Handover button. If you added a form inspection that need to show when you close a location, that form will appear and you are able to fill in the form. [Location Sign-off](/it/faq/siti/location-sign-off)_
- Cancel
