Once multiple areas have been indicated as **Ready For Inspection**, the client can go around with the contractor and sign off these locations as being completed (**Close and HandOver**).

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

To sign-off a location, click on **Plan Viewer** in the main menu

Navigate to the drawing that contains the location you want to sign-off

Click on the location

Click **Close with LSO** (location sign-off)

If a Location Sign-off form is setup, the form will open and you can fill this out.

If you close the inspection and pass it, the location is signed off and will turn green.

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **Device**

On **i****OS device**, we can do it like this way

<iframe src="https://player.vimeo.com/video/108713071" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

Tap on the location that is ready for sign-off.

Tap **Close/Handover** from the pop up (bottom right) that appears.

If a **Location sign-off (LSO) form** has been setup, this form will be opened.

Fill in this form with the client.

Tap **Change Workflow** in the bottom right hand corner

If the location is confirmed as ready for handover, then select **Closed Passed** for this inspection. Alternatively if the client does not believe the location is ready for handover then this inspection should be indicated as **Closed Failed**.

If the LSO was passed then the location will appear Green  , if the LSO was failed then it will return to its Blue state .

On **Android** **device**, we can do it as this way

Tap on the location that is ready for signoff

Tap “Close Location” from the pop up box that appears.

If a **Location sign-off (LSO) form** has been setup, this form will be opened.

Fill in this form with the client.

Tap on the wheel icon at the top right corner of the screen.

If the location is confirmed as ready for handover, then select “Pass” for this inspection. Alternatively if the client does not believe that the location is ready for handover then this inspection should be indicated as failed.

If needed you can add an extra comment when closing the form.

If the LSO was passed then the location will appear Green  , if the LSO was failed then it will return to its Blue state .
