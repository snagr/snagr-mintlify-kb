Once all issues have been signed off in a location and towards the completion of a project, the status of a location can be changed from being active to being ready for inspection. This will change the colour of the location from blue to yellow.

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

To mark a location Ready for Inspection, click on Plan Viewer in the main menu and make sure you in the issue mode.

Navigate to the drawing that contains the location you want to mark Ready for Inspection

Click on the location

Click "Ready for Inspection"

The location will turn yellow.

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **Device**

on **i****OS device**, we can do it as this way

<iframe src="https://player.vimeo.com/video/108713071" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

Tap on the location that is ready for inspection

Tap “Ready for Inspection” from the pop up (bottom left) box that appears.

The popup box will close automatically and the location will change from being Blue  to Yellow . This is a visual aid to see which locations are ready for inspection.

To return the location to appearing blue, repeat the first two steps.
