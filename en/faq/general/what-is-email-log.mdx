---
title: "What is Project Activity Log?"
---

Project Activity Log will record every basic movement of the general users and the project admin be able to track it anytime.

**<img src="/images/direct/1553573690492-1553573690492.png" alt="1553573690492" width="22" />** **Who** can view the Project Activity log?

If you are the project admin, you will be able to check the Project activity log from Project Administration &gt; Project activity Log

<img src="/images/direct/1557138717289-Admin_Website.001.jpeg" alt="Admin Website.001" />

You can select a particular user by "Username" to previews;

Or

select a particular "Mode" :

\- All

\- Inspection Mode (Sometimes will show as blank)

\- Defect Mode

\- Setup Mode

In addition, you can also sort the items by clicking the title.
