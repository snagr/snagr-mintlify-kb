title: "What is issue mode? What is inspection mode?"
---

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="20" />  **Device**

There are two modes within SnagR: Issue Mode and Inspection Mode. Be sure you are switched to the correct mode to carry out the activities accordingly.

**Issue mode**

Issue mode is used for plotting location-based issues. By default each issue record includes a photo, issue description, contractor responsible, due date, etc.

<img src="/images/uploads/127048-Getting_Started.007.jpeg" alt="Getting Started.007" />

<img src="/images/uploads/127041-Red_Flag_Emoji.png" alt="Red Flag Emoji" width="20" /> Learn how to [add](/en/issues/add-issues/how-to-add-an-issue) and [update](/en/issues/update-issues/how-to-update-issues) an issue.

**Inspection Mode**

Inspection mode is used for submitting digital forms.
