<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

Bundles are **files put together** that allows users to **download** an entire document pack onto their device in a simple click. Otherwise each document download would have to be done per file.

First, create the bundle name.

<img src="/images/uploads/128858-Website_Document.011.jpeg" alt="Website Document.011" />

Once you have named a bundle, drag files to it. Hover on the icon

<img src="/images/uploads/128861-Screen_Shot_2017-08-25_at_5.44.10_PM.png" alt="Screen Shot 2017 08 25 at 5.44.10 PM" />

 you should see <img src="/images/uploads/128862-564a0764a079075c11e9401a_modest-mouse-cursors-axure-widget-library.png" alt="564a0764a079075c11e9401a modest mouse cursors axure widget library" width="20" /> then you should be able to drag the file over.
