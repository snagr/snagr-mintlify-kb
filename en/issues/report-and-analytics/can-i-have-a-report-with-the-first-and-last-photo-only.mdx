---
title: "Can I have a report with the first and last photo only?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

Under Drawing Based Report, select Print Survey Report.

This exports an issue report of **all** **issues** with the first and last updated photo of each record.

<img src="/images/uploads/129910-Website_Issue_Mode.026.jpeg" alt="Website Issue Mode.026" />

If there is no photo record, the photo area will appear empty.
