title: "Where do I see issue notifications?"

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="20" />  **Device**

Note you only see in-app notifications if you have subscribed yourself to it or your admin have done it for you. In-app notifications are triggered instantly upon 1 issue creation or update.

<img src="/images/uploads/127041-Red_Flag_Emoji.png" alt="Red Flag Emoji" width="20" /> Learn how to set up subscriptions [for yourself](/en/issues/report-and-analytics/can-issue-reports-be-generated-automatically) and [for others](/en/set-up-project/notifications-project-level/how-to-set-up-issues-notifications-for-all-users).

Under **Menu**, go to **Notifications**.
