👤 **Who** can batch edit?

Only administrators can batch edit and batch delete issue records.

Go to **Dashboards** &gt; **Issue Dashboard**

**Select** list view <img src="/images/direct/1524737261007-Screen-Shot-2018-04-26-at-6.02.23-PM.png" alt="Screen Shot 2018 04 26 at 6.02.23 PM" width="23" />

<img src="/images/direct/1524552715862-Website-Issue-Mode.001.jpeg" alt="Website Issue Mode.001" />

Apply **filter(s)**

<img src="/images/direct/1524553231926-Website-Issue-Mode.002.jpeg" alt="Website Issue Mode.002" />

<img src="/images/direct/1524553689607-Website-Issue-Mode.003.jpeg" alt="Website Issue Mode.003" />

**_Why apply filter(s)?_**

It may be that a group of issues have been assigned to the wrong contractor, recorded on wrong drawing or recorded with a wrong issue category, type or description. In any case, to use batch edit efficiently, you want the issue dashboard to **display only the records that need to be edited.**

After filtering, click **Batch Edit**.

<img src="/images/direct/1524554794772-Website-Issue-Mode.004.jpeg" alt="Website Issue Mode.004" />

Click **Select All** &gt; Click **Edit (n) issue(s)**

<img src="/images/direct/1524554928596-Website-Issue-Mode.005.jpeg" alt="Website Issue Mode.005" />

<img src="/images/direct/1524555093165-Website-Issue-Mode.006.jpeg" alt="Website Issue Mode.006" />

<img src="/images/direct/1524555242899-Website-Issue-Mode.007.jpeg" alt="Website Issue Mode.007" />

❗Once you hit **Delete (n) Items**, the record will be removed from the web server.
