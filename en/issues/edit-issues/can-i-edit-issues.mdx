---
title: "Can I edit issues?"
---

**What** does editing an issue include?

\1. Re-assign issue to another contractor

\2. Change issue descriptions

\3. Update due by dates

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **Device**

Before you synchronise, you have the liberty to do any edits.

After you synchronise, you will have to edit issues on the website.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> How to know which issues have not been synchronised? Look for issue IDs that are 000001 or 900001. These are temporary IDs assigned, meaning they are not yet synchronised.

**<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="20" /> Who** can edit issues?

You can edit the issues you created. If you are an administrator, you can edit all issues.

**How** to edit issue?

Go to Plan Viewer or Issue Dashboard.

**Plan Viewer**

If you prefer to search and edit issues **based on locations**, go to Plan Viewer. Tap on an issue pin, and select <img src="/images/uploads/123646-Screen_Shot_2017-08-05_at_9.03.45_PM.png" alt="Screen Shot 2017 08 05 at 9.03.45 PM" width="30" /> to change issue properties.

<img src="/images/uploads/123682-Website_Issue_Mode.010.jpeg" alt="Website Issue Mode.010" />

**Issue Dashboard**

If you prefer to search issues with **more filters and selections**, such as date range, priority, and issue types, you may want to choose Issue Dashboard. There you will find the same editing icon <img src="/images/uploads/123648-Screen_Shot_2017-08-05_at_9.07.10_PM.png" alt="Screen Shot 2017 08 05 at 9.07.10 PM" width="22" /> .
