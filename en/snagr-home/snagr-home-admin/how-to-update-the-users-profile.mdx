**Click "SnagR Home / FM"**

Access the SnagR Home / FM New page.

**02**

**Click "Users"**

Navigate to the Users section.

<img src="/images/guidde/dCNxiF1RAHQW1rVZntiUF1_doc.png" alt="preview" />

**03**

**Apply filter**

Select the All option.

<img src="/images/guidde/fAY62TS9PhwK9X3MvCMg6R_doc.png" alt="preview" />

**04**

**Click "Edit User"**

Open the Edit User page.

<img src="/images/guidde/qWVFBCMF61wGGS6PuJZCLV_doc.png" alt="preview" />

**05**

**Click "Profile" to select others**

Choose the appropriate user role from the available options.

<img src="/images/guidde/ic8iAGrio99kwKJGrsKQvA_doc.png" alt="preview" />

**06**

**Click "Save"**

Save the changes to the user profile.
