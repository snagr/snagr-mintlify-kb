---
title: "How to edit user's detail?"
---

**Click "SnagR Home / FM"**

Access the SnagR Home / FM New page.

<img src="/images/guidde/nnxdketmRjPfqaBTUPrxTA_doc-2.png" alt="preview" />

**02**

**Click "Users"**

Navigate to the Users section.

<img src="/images/guidde/dCNxiF1RAHQW1rVZntiUF1_doc-2.png" alt="preview" />

**03**

**Apply filter**

Select the All option.

<img src="/images/guidde/fAY62TS9PhwK9X3MvCMg6R_doc-2.png" alt="preview" />

**04**

**Click "Edit User"**

Open the Edit User page.

<img src="/images/guidde/qWVFBCMF61wGGS6PuJZCLV_doc-2.png" alt="preview" />

**05**

**Click to edit the detail**

Edit detail.

<img src="/images/guidde/ic8iAGrio99kwKJGrsKQvA_doc-2.png" alt="preview" />

**06**

**Click "Save"**

Save the changes to the user profile.

<img src="/images/guidde/iiMDKmrg9Vd9QAANBHv9DM_doc-2.png" alt="preview" />

<Note>
Updating the user email or password would also affect the QR code on the welcome pack.

The QR code generated before changes will be invalid.

Please regenerate.
</Note>
