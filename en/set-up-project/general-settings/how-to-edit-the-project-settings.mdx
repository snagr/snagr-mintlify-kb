When a project is added some info is added for that project. You are able to edit most of the data after creating the project.

Like Contract number, Default Language, Project Contacts info, Logo, Clients user setting, Notifications sending time etc.

Login to the project

Go to the project Administration in the menu

Click on Project Settings

Here you can see the general information of the project

You can change the information if you like

To save the information, click "Update Project Settings" at the bottom of the page
