This is a company level feature

To view the current projects at the company.

Click on Projects under SnagR Accounts Settings.

Here you will see all the projects with the labels.

<img src="/images/direct/1546856432947-1546856432947.jpg" alt="1546856432947" />

You can click on **Edit Projects** to edit and check or uncheck **Show Active Projects**.

When a project is set as Finished it won't be shown at the login page of the company anymore.

If you're ready, you click on **Save** to save the changes or click on **Cancel** to discard the changes.

<img src="/images/direct/1537955814933-exclamation-mark.png" alt="exclamation mark" width="31" /> We **do not** recommend user changes the project name by themselves, kindly contact the SnagR support team if there is any reason have to edit the project name.
