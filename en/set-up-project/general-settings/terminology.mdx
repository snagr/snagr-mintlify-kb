This is a company level feature

Login to the Company Admin Area

Click on Terminology in the left menu

Here a grid shows with all the terminology that you can fill in optionally for projects. The terminology can be changed to the things you like to save for a project.

Program is a selection of terms to connect to a project quickly.

If you want to save a city per project, you can change for example Div 1 into City.

To change the items, click on the pencil icon

Change text and click on the blue tick to save (or the red stop sign if you don't want to save)

Below the grid you can choose if you want to show these additional labels when you add a project.

You can also choose to enable or disable the ability to add Users or Contractors from project level.
