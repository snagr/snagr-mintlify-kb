**What** are locations?

Project locations signify to SnagR what area of the project each issue or form belongs to.

For example, each location can signify a different room, so when an Issue is added the system knows that it has been added to Room 01 and not Room 02 or 03. An issue report will also state the location of an issue, meaning you do not have to go back to a drawing to visualise an issue's location.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> It is best to set up locations at the start of the project, throughout all drawings so that issues and forms can be added to all areas. Once set up, locations will not need to be added unless some have been missed.

<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="20" /> **Who** can set up locations?

Locations can only be added by an administrator. User rights are set and changed through the website.

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **Device**

on **i****OS device**, we can add the location pin as this way

Click on the “Location” button  in the menu pane at the bottom of your screen (if this is greyed out then administrator rights have not been granted)

A red target should appear in the center of the screen. Tap the room in which you wish to add the location in.

Continue to tap different areas to position it perfectly.

When happy, click “Place” at the bottom of the screen.

Add the location name (usual room name)

Add an external reference if required (these can then be linked to room specific data at a later stage such as room data sheets)

Tap "Add Location" to confirm. The location is placed. To place another location, repeat the steps above.

on **Android** **device**, we can add the location pin as this way

Click on “Add Location” in the menu (if this is greyed out then administrator rights have not been granted)

A red target should appear in the center of the screen. Tap within the room in which you wish to add the location in.

Continue to tap different areas to position it perfectly.

When happy, click “Place” at the top of the screen

Add the location name

Add an external reference if required (these can then be linked to room specific data such as room data sheets at a later stage)

Click “Add Location”

Continue this process for all locations.

An External Reference is an extra way to distinguish the locations from each other. You can use the External Reference to link Room Data Sheets to it for example. Also you can use the External Reference if you use 2 names for one location (e.g. location name of architect and another location name of the construction company).
