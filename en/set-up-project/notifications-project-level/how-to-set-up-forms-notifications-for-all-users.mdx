---
title: "How to set up forms notifications for all users?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

In SnagR, setting up a notification is a subscription. It details what information you wish to send out / receive automatically. These subscriptions produce automated reports via email to save you having to produce repetitive reports on a regular basis.

<img src="/images/uploads/137634-electric-light-bulb_1f4a1.png" alt="electric light bulb 1f4a1" width="25" /> **Tip****:** Subscriptions are incredibly helpful for adoption at the beginning of every project. It creates a reminder and keeps things going.

<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="25" /> **Who** can set up notifications for everyone?

Only administrators. If you are not an administrator, you may set up notifications for yourself. Click here to learn more.

**How to set up forms subscriptions?**

Click Subscription &gt; Create New Inspection Subscription.

<img src="/images/direct/1520563892658-Admin_Website.001.jpeg" alt="Admin Website.001" />

<img src="/images/direct/1520563920374-Admin_Website.002.jpeg" alt="Admin Website.002" />

Enter Subscription Title &gt; Select the User(s) and Contractor(s) who need to receive the notification &gt; Select Work Flow(s) Stages.

<img src="/images/direct/1520563939929-Admin_Website.003.jpeg" alt="Admin Website.003" />

<img src="/images/direct/1520563963309-Admin_Website.004.jpeg" alt="Admin Website.004" />

Work Flow stage subscription is now set up.

**If you need more filters...**

Before you hit Create Subscription, select Add Report Filters below.

<img src="/images/direct/1520563984409-Admin_Website.005.jpeg" alt="Admin Website.005" />

<img src="/images/direct/1520564021426-Admin_Website.006.jpeg" alt="Admin Website.006" />

You can add filters based on Drawing Set, Drawings, Locations and Owners.

Form notifications / update are sent instantly via in-app and email when the workflow is triggered.

Once you are happy, click Create Subscription.
