title: "How to set up issues notifications for all users?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

In SnagR, setting up a notification is a subscription. It details what information you wish to send out / receive automatically. These subscriptions produce automated reports via email to save you having to produce repetitive reports on a regular basis.

<img src="/images/uploads/137634-electric-light-bulb_1f4a1.png" alt="electric light bulb 1f4a1" width="25" /> **Tip****:** Subscriptions are incredibly helpful for adoption at the beginning of every project. It creates a reminder and keeps things going. A typical subscription would be a daily report of all issues created and updated that day.

<img src="/images/uploads/127190-Unknown_Man_Emoji.png" alt="Unknown Man Emoji" width="25" /> **Who** can set up notifications for everyone?

Only administrators. If you are not an administrator, you may set up notifications for yourself. Click here to learn more.

**How to set up issue subscriptions?**

In this example we will set up a typical subscription, i.e. a daily report of all issues created and updated that day.

Click Create New Issue Subscription.

<img src="/images/uploads/129578-Admin_Website.047.jpeg" alt="Admin Website.047" />

<img src="/images/uploads/129579-Admin_Website.048.jpeg" alt="Admin Website.048" />

Choose what type of subscription you would like to receive: Instant, Daily, Weekly or Monthly.

<img src="/images/uploads/129423-exclamation-mark.png" alt="exclamation mark" width="20" /> **Reminder****:** An instant notification will send 1 individual email per issue that meets the criteria of your subscription immediately the device is synchronised. Therefore these are mostly suited to emergency issues only. For a general report, a daily subscription is much better suited so that 1 email is sent including all of the Issues added and updated that day.

<img src="/images/uploads/129597-Admin_Website.049.jpeg" alt="Admin Website.049" />

If you select Daily, Weekly or Monthly you will be presented the choice of selecting whether you want to include All Issues, or simply only those Issues that have been updated with a set number of days. Select which option you prefer.

If you select a Weekly report, you will also be able to specify which day of the week you would like to receive it.

<img src="/images/uploads/129581-Admin_Website.050.jpeg" alt="Admin Website.050" />

<img src="/images/uploads/137635-notebook-with-decorative-cover_1f4d4.png" alt="notebook with decorative cover 1f4d4" width="20" /> **Note**: Users see a report showing all issues that meet your filter criteria; however, contractors will only see a report displaying the issues assigned to them.

<img src="/images/uploads/129583-Admin_Website.051.jpeg" alt="Admin Website.051" />

A daily issue subscription is now set up.

**If you need more filters to the report...**

Before you hit Create Subscription, select Add Report Filters below.

<img src="/images/uploads/129584-Admin_Website.052.jpeg" alt="Admin Website.052" />

<img src="/images/uploads/129585-Admin_Website.053.jpeg" alt="Admin Website.053" />

You can add filters based on issue types, drawings, locations, users, priority and the countdown days of when the issue is due.

Once you are happy, click Create Subscription.
