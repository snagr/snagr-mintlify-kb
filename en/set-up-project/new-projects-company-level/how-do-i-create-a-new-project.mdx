---
title: "How do I create a new project?"
---

You must be a Company Administrator to create a new project under your company domain. Also, you will have to be given an "Add new project" permission to do so.

Click on **"New project"**

<img src="/images/direct/1585819573704-Website-Issue-Mode.001.jpeg" alt="Website Issue Mode.001" />

To create a completely new project environment, please choose **"Add new project & new DB"** and click on **"Next"**

<img src="/images/direct/1585819590352-Website-Issue-Mode.002.jpeg" alt="Website Issue Mode.002" />

Fill in project information

The basic information you will have to enter are Project Name, Project Path and Contract no.

For project path, you just need to enter the path only e.g. if the company domain is https://abccompany.snagrweb.com and you wish to have a URL for the new project as https://abccompany.snagrweb.com/projectA , then you should just fill in " projectA ".

 <img src="/images/direct/1585817025239-1585817025239.png" alt="helpjuice production/uploads/upload/image/3577/direct/1585817025239 1585817025239" width="33" />Once the project URL is created, there is no way to change it. Be careful!

<img src="/images/direct/1585819624031-Website-Issue-Mode.003.jpeg" alt="Website Issue Mode.003" />

Read the terms and conditions and click **"Create New Project"**

<img src="/images/direct/1585819709197-Website-Issue-Mode.004.jpeg" alt="helpjuice production/uploads/upload/image/3577/direct/1585819709197 Website Issue Mode.004" />

Once the new project environment is successfully created, it will be added to the project list on the login page.

Please be reminded to add project admins to the newly added project so that they can further set up the project environment.

<img src="/images/direct/1585817067771-1585817067771.png" alt="helpjuice production/uploads/upload/image/3577/direct/1585817067771 1585817067771" width="29" />Note: It requires a valid license of your company to create new projects. Otherwise, you will not be authorised to do so. If you fail to proceed the above process, please contact SnagR for further assistance.
