---
title: "How do I clone project?"
---

You must be a Company Administrator to create a new project under your company domain. Also, you will have to be given an "Add new project" permission to do so.

Click on **"New project"**

<img src="/images/direct/1585820085120-Website-Issue-Mode-2.005.jpeg" alt="Website Issue Mode 2.005" />

To clone existing project, please choose **"Clone Existing project"** and click on **"Next"**

<img src="/images/direct/1585820123341-Website-Issue-Mode-2.006.jpeg" alt="Website Issue Mode 2.006" />

Fill in project information

The basic information you will have to enter are Project Name, Project Path and Contract number.

For project path, you just need to enter the path only e.g. If the company domain is https://abccompany.snagrweb.com and you wish to have a URL for the new project as https://abccompany.snagrweb.com/projectA , then you should just fill in " projectA " .

<img src="/images/direct/1585820209039-1585820209039.png" alt="1585820209039" width="32" />Once the project URL is created, there is no way to change it. Be careful!

<img src="/images/direct/1585820229560-Website-Issue-Mode-2.007.jpeg" alt="Website Issue Mode 2.007" />

Select existing project to clone and what will be cloned from the selected existing project

<img src="/images/direct/1585820272368-Website-Issue-Mode-2.008.jpeg" alt="Website Issue Mode 2.008" />

Read the terms and conditions and click **"Clone Project"**

<img src="/images/direct/1585820291911-Website-Issue-Mode-2.009.jpeg" alt="Website Issue Mode 2.009" />

Once the new project environment is successfully created, it will be added to the project list on the login page.

Please be reminded to add project admins to the newly added project on company level so that they can further set up the project environment.

<img src="/images/direct/1585820328621-1585820328621.png" alt="1585820328621" width="33" />Note: It requires a valid license of your company to create new project. Otherwise, you will not be authorised to do so. If you fail to proceed the above process, please contact SnagR for further assistance.

Learn [how to add new project](/en/set-up-project/new-projects-company-level/how-do-i-create-a-new-project).
