---
title: "What is the quickest way to set up repetitive units?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

If the room / unit types are going to repeat itself, the easiest way to set up would be to use **repeat drawings**.

In this example a residential building has an identical set of typical units on each floor.

To quickly set up for this, the plan would be to:

\1. [Upload all typical layout plans](/en/set-up-project/drawings-project-level/how-to-upload-drawings)

\2. [Set up locations for all layout plans](/en/set-up-project/locations-project-level/how-to-set-up-locations-on-drawings)

\3. Repeat drawings

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> Note you want to set up the locations before repeating drawings because in this case the locations can be repeated too.

After you have uploaded the plans and set them up with locations, here is how you can repeat the drawings:

<img src="/images/uploads/129424-Admin_Website.024.jpeg" alt="Admin Website.024" />

<img src="/images/uploads/129425-Admin_Website.025.jpeg" alt="Admin Website.025" />

In this example, Unit 6A will be created based on the drawing Unit 5A. The checkbox next to generate locations is checked, meaning it also **replicates locations** from Unit 5A to Unit 6A. You can repeat up to 10 drawings each time.

Before you hit Upload Drawings, check that you have **chosen a drawing set** for these repeated drawings. In this example the drawing Unit 6A will fall under the drawing set 6F. In any case you can always make changes by [editing an existing drawing](/en/set-up-project/drawings-project-level/how-to-edit-existing-drawing).

<img src="/images/uploads/129426-Admin_Website.026.jpeg" alt="Admin Website.026" />

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> Repeat drawings does not only make set up a lot easier, it also saves storage space of the device. For example if your typical layout plans take up a total of 3 MB, no matter how many times you repeat drawings, repeated drawings and typical drawings will altogether stay 3 MB because the mechanism behind repeated drawings is only to point to the master drawing.
