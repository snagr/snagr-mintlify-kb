---
title: "How to create drawing sets / folders?"
---

Drawings sets work like folders. By having drawing sets, it helps to:

1. Search for drawings efficiently and manage drawing updates
2. Use as a report filter (generate issue report based on drawing sets)

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

Go to Project Administration &gt; Drawings

**Type** in drawing set name &gt; Click **Add Drawing Set**

<img src="/images/uploads/129320-Website_Issue_Mode.001.jpeg" alt="Website Issue Mode.001" />

**_Example_**

If it is a building project, you may want to create drawing sets by floor, i.e., 5F, 6F, 7F...etc.

When generating reports, you can easily create an issue report by floor by choosing a drawing set.
