title: "How to prepare and upload drawings?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

There are two ways to upload drawings:

\1. Upload by **zip file**  
(Recommended when you have &gt;5 drawings to upload)

\2. Upload by **individual files**  
(Recommended when you have &lt;5 drawings to upload)

**Group drawings**

In larger projects, it is good housekeeping to group drawings. To achieve this it is best to [set up drawing sets folder](/en/set-up-project/drawings-project-level/how-to-group-drawings) before uploading drawings. If you are uploading with zip files, a separate PDF zip file is required for each drawing set folder.

E.g. if the project consisted of 3 buildings, a zip file is needed for each separate building.

**Drawing titles**

If you upload through a zip file, the drawing title will be taken from the file name directly.

If individual files, you will name the drawing title separately.

<img src="/images/uploads/127191-Pencil_Emoji.png" alt="Pencil Emoji" width="20" /> Be sure the filenames don't contain special characters like , . & % etc. The system doesn't allow those characters.

**PDF scaling**

If it is a PDF file, you can adjust the scale by percentages. That will affect the drawing dimension displayed on the plan viewer.

If it is a JPEG or PNG file, scaling by percentages will not apply. You have to adjust your image file sizes before uploading.

**Drawing set**

Before you hit upload, don't forget to select the drawing set you want these drawings to be added to. You can choose the drawing set on the top of the page, at step #2.2.1.

Once everything is set, click **Upload Drawings**.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> SnagR automatically converts original PDFs to GIF images. This reduces the size of each file and improves the efficiency of the software.
