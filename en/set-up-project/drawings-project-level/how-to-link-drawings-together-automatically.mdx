**Generate navigation links for all drawing sets**

In this example it is a residential project with multiple units on a floor. The drawing sets are created by floor, e.g., 5F, 6F, 7F and etc. Each drawing sets consists of the typical unit layout, e.g., 5A, 5B, 5C, 5D, and etc.

You can have these drill down links set up automatically and aligned perfectly:

Choose Navigation Drawing Set means assigning a drawing set to place these navigation drawings. Typically a drawing set named Navigation is created to store these auto generate drawings.

**How about only specific drawing sets?**

Instead of Auto Generate All Nav Plans, choose **Auto Generate Single Drawing Set Nav Plan**.

<img src="/images/uploads/129347-Admin_Website.012.jpeg" alt="Admin Website.012" />

First, choose the drawing set you want to have navigation links automatically set up. Next, choose where to store these auto generate drawings.
