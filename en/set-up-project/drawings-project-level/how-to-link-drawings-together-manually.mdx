---
title: "How to link drawings together (manually)?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

After you have uploaded drawings, you can link them together to make navigation on the app a bit easier.

To set up the links, go to Link &gt; Link Drawings, or the Plan Viewer set up mode directly.

<img src="/images/uploads/129335-Website_Issue_Mode.005.jpeg" alt="Website Issue Mode.005" />

<img src="/images/uploads/129341-Website_Issue_Mode.006.jpeg" alt="Website Issue Mode.006" />

<img src="/images/uploads/129342-Website_Issue_Mode.007.jpeg" alt="Website Issue Mode.007" />

If you have a lot of drill downs to set up on a drawing, you have the option to select confirm and add next to speed up your set up process.

<img src="/images/uploads/129343-Website_Issue_Mode.008.jpeg" alt="Website Issue Mode.008" />

Confirm!

<img src="/images/uploads/129344-Website_Issue_Mode.009.jpeg" alt="Website Issue Mode.009" />

You can Move/Edit/Delete the drilldown by clicking the existing drilldown on the setup mode.
