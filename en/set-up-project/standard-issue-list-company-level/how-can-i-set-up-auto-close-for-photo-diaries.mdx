---
title: "How can I enable auto-close for photo diaries?"
---

Auto-close feature is designed for photo diaries because these records will not follow a typical issue rectification process. If a user selects an issue category that is enabled with "auto-close", the record will automatically close itself when the user sync from mobile app or refresh from the browser.

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

Login to Company Admin Area. Only company admin can update issue categories to be auto closed.
