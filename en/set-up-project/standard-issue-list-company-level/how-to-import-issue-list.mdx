title: "How to import issue list?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

First login to the Company Admin Area. If you are not a company admin, you will not see Login to Company Admin Area.

<img src="/images/uploads/137649-Admin_Website.085.jpeg" alt="Admin Website.085" />

On the menu, go to Issue Library. Select Import New Issues to upload your spreadsheet.

<img src="/images/uploads/137650-Admin_Website.086.jpeg" alt="Admin Website.086" />

<img src="/images/uploads/137651-Admin_Website.087.jpeg" alt="Admin Website.087" />

<img src="/images/uploads/137652-Admin_Website.088.jpeg" alt="Admin Website.088" />

There you go.

<img src="/images/uploads/137653-notebook-with-decorative-cover_1f4d4.png" alt="notebook with decorative cover 1f4d4" width="20" /> **Note:** If all items are displayed in green like the above, the import is good to go. If there should be any errors, e.g. a duplicated item, the system would highlight them in red. In those case you may want to modify the spreadsheet to proceed again.
