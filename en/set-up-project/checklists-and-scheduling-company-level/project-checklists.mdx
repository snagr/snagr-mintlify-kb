This is a company level feature.

_For project checklists you only add a name for the checklist at company level. The rest you add at project level (part 2)._

Click on Company Inspections and on Project Checklists in the submenu.

Click "Create New Project Checklist" to create a new one. (if you already made one, you can also edit it, by clicking "Edit")

Fill in the name and initials and click "Create Project Checklist"

To fill the project checklist, login to the project and see Project Checklists for more information.
