**Construction Stages**

It's possible to add standard schedules to monitor the progress per location. For example: A standard room in the project always needs a couple of steps to finish.

Then you are able to monitor the progress per location. Per item you can set the percentage complete.

To use the schedules for your project you need import them first to the specific locations.

Click on "Import /export CS Schedules"

Select the schedule you want to import. This is added at company level ([Web - Construction Stages - Company level](http://support.snagr.co.uk/display/help/Web+-+Construction+Stages+-+Company+level)), but fine tuned at project level.

And select the drawing and/ or location types to which you want to add this schedule.

And click on "Export Template".

It will ask you to save a file to your computer. Save the file and open it.

It will show you the details of the schedules you exported with some extra info.

Column A shows the Location ID, B the external reference of the location, Column C the Inspection initials (should all be the same), Column D shows the Drawing Title, Column E shows the Location name. These columns you leave unchanged. The items you would like to change are column F and G.

Here you can define what the start and end date is of the schedule you are going to add. It's by default set to today + the days put in the schedule at company level. Change the dates if needed. If you have a bigger room that needs twice as much time as the normal rooms, you can extend the schedule time by setting a later end date. This will stretch the schedule.

You can also delete one or more locations if you want to exclude specific locations.

If you're ready, save the file again.

Click on "Re-import Template". Another page will show.

Select the file you just saved and click on "Import Items".

Any errors will show in red. In the last column you will see the reason why it's wrong. If the table is all green, you can import. To do this, click "Import Items" above the grid.

To view the details of the schedules, go to the main page of the construction stages. Choose a schedule that you want to see and if needed select the drawing. Click "View Plots". In the grid at the bottom of the page you will see all the schedules.

You can see the general information in the grid, for example the percentage complete.

To open the schedule, click on the edit button

To view it on plan viewer, click on the plan viewer icon

To make a pdf of the schedule, click on the pdf icon

To delete the schedule, click on the delete button

You can also use the date filter to search the right schedules ("Stages Finished between/Stages NOT Finished between/Due to Finish soon)

You can also make a matrix in days and percentages.
