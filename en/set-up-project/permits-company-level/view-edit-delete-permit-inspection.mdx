This is a company level feature

Once set up it may be desirable to edit a form’s inspection so it behaves slightly differently than when it was first created. For example, it may no longer be desirable for the inspection to remain on the device permanently. This section shows how each inspection can be easily edited.

**Edit Permit Inspection**

Click on Company Inspections

Click on Permits from the expanded drop down menu

The Permit Inspections page will display. Already created inspections will display in the table.

To edit an inspection click the edit button  in the row of that inspection.

A pop up box showing the inspection’s details will show.

Edit all of the details that you wish to change.

Click Submit to confirm the changes.

If you wish to remove the inspection entirely then click “Remove”.

**Note: after confirmation this will permanently delete the inspection which will effect previously conducted inspection. Please contact SnagR support before undertaking this step if it is not a brand new inspection.**

**Edit Permit Form**

Go to the Permit Inspections. Then click “Edit Permit” in the row of the inspection which contains the form you wish to edit.

This opens the “Manage Inspection’s Forms” where the form(s) attached to that inspection will display.

Here you can edit the Permit details. On clicking the edit pencil button

A pop up box containing the editable information of the form will display.

To edit information such as the title, its description, whether it is a pass fail type form or whether the form remains current (turning this off will mean it does not display in the inspection list on mobile devices, which acts as if the form has been removed but does not delete previous data)

To change the GIF image that is displayed for the form click the edit button  and then upload the new image to use.

To add an additional page to the form (e.g. page of photograph attachments) click “Add Page” and upload the new background.

When you are satisfied with the changes click “Save”.
