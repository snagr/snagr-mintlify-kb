_To add a permit you first must create an inspection. The details of an inspection may be exactly the same as the permit itself (this is often the case when the inspection only consists of one permit)_

Click on Company Inspections

Click on Permits from the expanded drop down menu

The Permit Inspections page will display. Already created inspections will display in the table.

To add a new inspection click “Add Permit Inspections”

Insert the name of the inspection (can be the permit’s name).

Insert an Inspection code (max 6 alphanumeric characters).

If you wish the inspection to remain on the device permanently then select “Keep on device?”

If you wish this inspection to be able to be started on a device rather than having to be first started through the website then select “Can add on device?”

When you are happy with your inspection click “Submit”. To add a permit form, go to [Add Permit](/en/set-up-project/permits-company-level/add-permit).
