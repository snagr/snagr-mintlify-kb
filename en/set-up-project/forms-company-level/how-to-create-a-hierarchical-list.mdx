First, login to **Company Admin Area**. Only Company admin can see this button.

<img src="/images/direct/1521177204174-Admin_Website.001.jpeg" alt="Admin Website.001" />

Go to **Company Inspections** &gt; **Hierarchical List**

Click Add New List button, input the List name and Submit.

<img src="/images/direct/1539333966955-Admin_Website.002.jpeg" alt="Admin Website.002" />

Click **Import List items** then import the prepared excel list.  
[Click here to download an import template (Excel SpreadSheet .xls)](http://demo40.snagr.com.hk/Build/ImportTemplates/SnagR-Hierarchical-Lists-Import-Template.xls)

<img src="/images/direct/1539333981760-Admin_Website.003.jpeg" alt="Admin Website.003" />

<img src="/images/direct/1539334005969-Admin_Website.004.jpeg" alt="Admin Website.004" />

Press **Save this data** when everything's okay (green).

<img src="/images/direct/1539334023771-Admin_Website.005.jpeg" alt="Admin Website.005" />

Done.

You have created a Hierarchical List!

Free feel to have a look of the sub list item by click in the **Edit Sub List** button.

**Then, How can we set up the hierarchical list on the inspection form?**

I am going to show you now, follow me!

First, Please go to the form wizard by the

<img src="/images/direct/1539336214568-Screen-Shot-2018-10-11-at-11.47.40-AM.png" alt="Screen Shot 2018 10 11 at 11.47.40 AM" />

 button on "Manage Inspection's Forms" page!

<img src="/images/direct/1539336410821-Screen-Shot-2018-10-12-at-5.26.40-PM.png" alt="Screen Shot 2018 10 12 at 5.26.40 PM" />

Select the fields and update the type to the HierarchicalList and choose a List Set (List Name).

<img src="/images/direct/1539334151254-Admin_Website.009.jpeg" alt="Admin Website.009" />

<img src="/images/direct/1539334170369-Admin_Website.010.jpeg" alt="Admin Website.010" />

Named those field title.

Click the level 2 field, select "Dependent" and "Parent List" to link with the level 1 and click the level 3 field, select "Dependent" and "Parent List" to link with the level 2.

And **Save**.
