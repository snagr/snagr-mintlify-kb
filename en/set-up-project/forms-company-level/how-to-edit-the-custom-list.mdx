---
title: "How to edit custom list?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

First, login to **Company Admin Area**. Only Company admin can see this button.

<img src="/images/direct/1521177204174-Admin_Website.001.jpeg" alt="Admin Website.001" />

Go to **Company Inspections** &gt; **List**

### **1. Edit list name**

Click **icon** <img src="/images/direct/1523848840678-Screen-Shot-2018-04-16-at-11.19.54-AM.png" alt="Screen Shot 2018 04 16 at 11.19.54 AM" width="26" /> to edit **List Code**.

<img src="/images/direct/1523850491638-Admin_Websiteeee.001.jpeg" alt="Admin Websiteeee.001" />

<img src="/images/direct/1523850514713-Admin_Websiteeee.002.jpeg" alt="Admin Websiteeee.002" />

### 2. Edit list Items

Click Edit **List Items**.

<img src="/images/direct/1523850541986-Admin_Websiteeee.003.jpeg" alt="Admin Websiteeee.003" />

Click **icon** <img src="/images/direct/1523848840678-Screen-Shot-2018-04-16-at-11.19.54-AM.png" alt="Screen Shot 2018 04 16 at 11.19.54 AM" width="26" /> to edit item.

<img src="/images/direct/1523850608498-Admin_Websiteeee.004.jpeg" alt="Admin Websiteeee.004" />

<img src="/images/direct/1523850629826-Admin_Websiteeee.005.jpeg" alt="Admin Websiteeee.005" />

### 3. Add List Items

Click **Add List Item(s)** at the top

<img src="/images/direct/1524724551076-1523850608498-Admin_Websiteeee.004.jpeg" alt="1523850608498 Admin Websiteeee.004" />

<img src="/images/direct/1523849567158-exclamation-mark.png" alt="exclamation mark" width="23" />Note that you can only rename items, you **cannot delete** items and **cannot** **change the item sort order.**
