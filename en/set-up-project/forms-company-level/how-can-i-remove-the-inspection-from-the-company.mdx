**Note: after confirmation, this will permanently delete the inspection which will effect previously conducted inspection. Please contact SnagR support before undertaking this step if it is not a brand new inspection.**

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

First, login to the **Company Admin Area**. Only Company admin can see this button.

<img src="/images/direct/1521177204174-Admin_Website.001.jpeg" alt="Admin Website.001" />

### Go to **Company Inspections &gt; Inspections**.

The Form Inspections page will display. Already created inspections will display in the table.

To edit an inspection click the edit button  in the row of that inspection.

A pop up box showing the inspection’s details will show.

If you wish to remove the inspection entirely then click “Remove”.

Fill in DELETE at the textfield if you are sure you want to delete this Inspection.
