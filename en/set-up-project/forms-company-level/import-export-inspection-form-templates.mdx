---
title: "Import/Export Inspection Form Templates"
---

It is possible to import and export inspection template from one project to another in SnagR.

Why would you need it?

You may use this feature to test inspection forms set up at a training domain, without affecting set up on your production site. You can make as many changes as you want, and test the process sufficiently before you export the inspection template and import to the actual site for others to administrate and use it.

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

<img src="/images/direct/1533026752795-Admin_Website.001.jpeg" alt="Admin Website.001" />

First, go the project which you need to clone the inspection form from, let's say Company environement A.

Login to **Company Admin Area**. (Only Company admin can see this button.)

<img src="/images/direct/1557116033553-Admin_Website.001.jpeg" alt="Admin Website.001" />

Go to **Company Inspections** &gt; **Inspections,** scroll to the bottom of the page then you can see **Export Inspection Template** button.  
Click to proceed.

<img src="/images/direct/1557116045410-Admin_Website.002.jpeg" alt="Admin Website.002" />

Select the inspection you want to export and click **Export Inspection Template**.

Great, we are now halfway through!

Next, go to the project where you want to import the inspection template, let's say Company environment B.

<img src="/images/direct/1557116066999-Admin_Website.003.jpeg" alt="helpjuice production/uploads/upload/image/3577/direct/1557116066999 Admin Website.003" />

<img src="/images/direct/1557116113495-Admin_Website.004.jpeg" alt="Admin Website.004" />

Go to **Company Inspections** &gt; **Inspections,** scroll to the bottom of the page then you can see **Import inspection template** button.  
Click to proceed.

This is the Inspection Template file you export from Company environment A :

<img src="/images/direct/1533027359580-Screen-Shot-2018-07-31-at-4.54.50-PM.png" alt="Screen Shot 2018 07 31 at 4.54.50 PM" />

<img src="/images/direct/1537344676308-Admin_Website.170.jpeg" alt="Admin Website.170" />

Upload the file and click **Import Inspection Template**.

<img src="/images/direct/1533028033223-Admin_Website.007.jpeg" alt="Admin Website.007" />

<img src="/images/direct/1557116224310-Admin_Website.007.jpeg" alt="Admin Website.007" />

Input the replaced inspection name & code, click **Update Schedules** if needed.

Or you can leave it blank to use the original.

<img src="/images/direct/1557116212524-1557116212524.jpeg" alt="1557116212524" />

Click **Update Form** to swap to the form preview.

<img src="/images/direct/1557116661435-Admin_Website.010.jpeg" alt="Admin Website.010" />

Input the replaced form name & code, click **Update Schedules** if needed.

Or you can leave it blank to use the original.

Confirm these are the inspection templates you want to import, Click **Import Template to Company Inspection** button to finish.

Inspection template(s) are now successfully imported.

Note: This feature does not support versioning. This means that if you have imported the inspection template from Company environement A to Company environement B before, you will not be able to import the same inspection template again if you make any changes to the template in either projects. This is because the inspection codes and form codes remain the same, and they will appear as duplicate and cause an error. Importing changes is not recommended, as this can make your set up environment less maintainable.
