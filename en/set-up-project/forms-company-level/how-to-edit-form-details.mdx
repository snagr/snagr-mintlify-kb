This is a company level feature.

Once set up it may be desirable to edit a form details so it behaves slightly differently than when it was first created.  
For example, you might need to update or add more form page.  
This section shows how each inspection can be easily edited.

<img src="/images/direct/1560249625059-danger-icon-4.jpg" alt="danger icon 4" width="16" /> The change will also affect to the previous form.

**Login to Company Admin Area**

Click on **Company Inspections**

Click on **Inspections** from the expanded drop-down menu

Already created inspections will display in the table.  
Please click the <img src="/images/direct/1560250288633-Screenshot-2019-06-11-at-6.51.21-PM.png" alt="Screenshot 2019 06 11 at 6.51.21 PM" width="45" /> button in the row of that inspection to entry to the Manage Inspection's Form page.

<img src="/images/direct/1560250084752-1560250084752.jpeg" alt="1560250084752" />

To edit an inspection click the edit button  in the row of that form.

A pop-up box of the Form details will show.

<img src="/images/direct/1560250471634-Screenshot-2019-06-11-at-6.52.32-PM.png" alt="Screenshot 2019 06 11 at 6.52.32 PM" />

Edit Form Details window pop-up.  
You are able to edit all of the details that you wish to change.

If this form is going to have Closed(Passed) and Closed(Failed) as a closed option then select **Has Pass/Fail?**

_Once you disabled the form you can never enable it._

<img src="/images/direct/1560250629440-1560250629440.jpeg" alt="1560250629440" />

Click **Save** to confirm the changes.

<img src="/images/direct/1560250950420-danger-icon-4.jpg" alt="danger icon 4" width="23" /> _Note: after confirmation, this will permanently change the inspection's form which will affect previously conducted inspection. Please contact SnagR support before undertaking this step if it is not a brand new inspection._
