---
title: "Can the contractor be automatically selected when a specific issue type is selected?"
---

SnagR allows linking up issue category/type and contractor group.  
Each issue type can be linked up to specific contractor group(s) in the project.  
Project admin can fully utilise this function to save up the time for users to choose contractor from a long list and avoid mistake made during issue recording process.

<img src="/images/direct/1554786731372-1554786731372.png" alt="1554786731372" width="26" /> **Website**

Go to Project Administration &gt; Issue Library

<img src="/images/direct/1554871111492-Document_Website.001.jpeg" alt="Document Website.001" />

Search for the issue category/type that you want to assign contractor group to

<img src="/images/direct/1554871166704-Document_Website.002.jpeg" alt="Document Website.002" />

Click " Add/Edit Contractors"

<img src="/images/direct/1554871218368-Document_Website.003.jpeg" alt="Document Website.003" />

Choose the contractor that you would like to assign to the selected issue category/issue type and click "Save"

Note: You can select more than one contractor from the project contractor list here. For example, if you choose 2 contractors from the project contractor list, the items available for selection will be limited to those two contractors instead of a full project contractor list during issue recording process.

<img src="/images/direct/1554871530047-Document_Website.004.jpeg" alt="Document Website.004" />

Contractor is assigned to the issue type "type1dxb" under issue category "cat1dxb".
