---
title: "I can't see the issue list when I add issues. What is wrong?"
---

After you added an issue list on Company Admin Area, it is not enabled on project level by default, so don't forget to also enable it on project level.

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

Go to Project Administration &gt; Issue Library, select **Manage Issue Categories**.

<img src="/images/uploads/147241-Admin_Website.106.jpeg" alt="Admin Website.106" />

Next, in the pop up window, check the Issue Categories you would like to enable, and click **Update Issue Categories**.

<img src="/images/uploads/147242-Admin_Website.107.jpeg" alt="Admin Website.107" />
