title: "How to edit users and contractors?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

**Edit Users**

Go to Project Administration &gt; Users.

To make changes to user account, click Edit User.

<img src="/images/uploads/129626-Admin_Website.062.jpeg" alt="Admin Website.062" />

<img src="/images/uploads/129625-Admin_Website.063.jpeg" alt="Admin Website.063" />

From there you are able to edit the username, full name, email address, user permission, enable/disable the user account on this project and reset user password.

- <img src="/images/direct/1556878137919-1556878137919.png" alt="1556878137919" width="26" /> What's **Enabled?** If you would like the user to access the system, check enabled. If you would not like the user to have access anymore, uncheck the box. They would not be able to login to the system then. Note a user can be disabled but cannot be deleted. This is to protect the project data such that if a user has created any issues or forms previously the record always remain.

**Edit Contractors**

Go to Project Administration &gt; Contractors.

To make changes to contractor account, click Edit.

<img src="/images/uploads/129627-Admin_Website.064.jpeg" alt="Admin Website.064" />

<img src="/images/uploads/129628-Admin_Website.065.jpeg" alt="Admin Website.065" />

From there you are able to edit contractor email contact, Edit password, enable/disable the contractor on this project and Inspection form permissions. Note by default contractor permission in issue mode is Can Fix and this cannot be changed.

- <img src="/images/direct/1556878137919-1556878137919.png" alt="1556878137919" width="26" /> What's **Enabled?** If you would like the user to access the system, check enabled. If you would not like the user to have access anymore, uncheck the box. They would not be able to login to the system then. Note a user can be disabled but cannot be deleted. This is to protect the project data such that if a user has created any issues or forms previously the record always remain.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="25" /> To change the contractor name and initials you need to be the company administrator to do so.
