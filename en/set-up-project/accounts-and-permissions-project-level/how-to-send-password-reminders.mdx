---
title: "How to send password reminders?"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

**Users （Older version)**

To remind password for individual users, click Send PW.

To remind password for all users, click Remind All Password at the bottom of the page.

<img src="/images/uploads/129622-Admin_Website.065.jpeg" alt="Admin Website.065" />

**Users （New version)**

<img src="/images/direct/1561364991197-Admin_Website.001.jpeg" alt="Admin Website.001" />

On the new version, you can only send them a password reset email instead of the remind password email.

To send password reset email to individual users, click Send.

To send password reset email for all users, click Remind All User Logins at the bottom of the page.

**Contractors**

To remind password for individual contractor, click Send PW.

To remind password for all contractors, click Remind All Password at the bottom of the page.
