---
title: "How to reset Two-Factor Authentication key?"
---

Sometimes, user is unable to use the device with the Authenticator app installed on it. Or they have a new device and have to reinstall the authenticator app again. In such cases, they need to contact their project administrator to reset the secret key (QR code).

Here is how project administrator reset the verification key:

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **Website**

**Login to the project**

<img src="/images/direct/1547024118686-Admin_Website.001.jpeg" alt="Admin Website.001" />

Go to **Project Administration** &gt; **Users**

<img src="/images/direct/1547024159712-Admin_Website.006.jpeg" alt="Admin Website.006" />

Search the user and click **Reset Key** to reset the verification key for this particular user

<img src="/images/direct/1547024219105-Admin_Website.007.jpeg" alt="Admin Website.007" />

When the user login to SnagR on website, he will be asked to scan the verification key (QR Code) again.
