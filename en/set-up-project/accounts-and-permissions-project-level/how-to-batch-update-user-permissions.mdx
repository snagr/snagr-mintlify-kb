[/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues](/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues)

Are you ready?

Here we go!

<img src="/images/direct/1556861051789-Admin_Website.001.jpeg" alt="Admin Website.001" />

"Project Administration" &gt; "Users" &gt; Batch Edit User Permissions"

<img src="/images/direct/1556861263472-Admin_Website.002.jpeg" alt="Admin Website.002" />

Select Users to edit permission  
You can select multiple users by the search for a keyword.

**Option 1 - load permissions**

<img src="/images/direct/1556861281517-Admin_Website.003.jpeg" alt="Admin Website.003" />

If there is an existing user who already has the permission which you want to clone, please select to loaded.

<img src="/images/direct/1556862429203-Admin_Website.004.jpeg" alt="Admin Website.004" />

Check the permission of each category.

**Option 2 - Create permissions**

<img src="/images/direct/1556863746285-Admin_Website.005.jpeg" alt="Admin Website.005" />

If there are no existing user permissions to load, you have to edit the permissions of each category to the selected user(s).

Then,

<img src="/images/direct/1556861904031-1556861904031.png" alt="1556861904031" />

Click "Update User(s) (xxxxxxxx) Only" to update specify category permission to selected user(s).

Or

<img src="/images/direct/1556861873272-1556861873272.png" alt="1556861873272" />

Click "Update All Permissions for all selected User(s)" to update all categories permission to the selected user(s).
