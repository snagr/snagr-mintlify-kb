---
title: "How to set permissions for KPI dashboards?"
---

Only the **administrators** can set the permission for the KPI Dashboard.

**How to set up？**

**<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> Website**

<img src="/images/direct/1536925572950-Website-Custom-Report.003.jpeg" alt="Website Custom Report.003" />

\1. Go to **Project Administration &gt; KPI Dashboards**

\2. If your project has multiple KPI Dashboard, choose the one you would like to manage access from the **drop down list**.

\3. Select the user(s) you want to manage access, and **move the user**(s) to "Available Users" or "Assigned Users" via

<img src="/images/direct/1532061783369-Screen-Shot-2018-07-20-at-12.42.07-PM.png" alt="Screen Shot 2018 07 20 at 12.42.07 PM" />

 or

<img src="/images/direct/1532061854641-Screen-Shot-2018-07-20-at-12.42.02-PM.png" alt="Screen Shot 2018 07 20 at 12.42.02 PM" />

<img src="/images/direct/1531994672198-exclamation-mark.png" alt="exclamation mark" width="28" />Please note that the system will not automatically set the newly added user to be able to view KPI Dashboard(s). Don't forget to give new users access for this too when you create a new account.
