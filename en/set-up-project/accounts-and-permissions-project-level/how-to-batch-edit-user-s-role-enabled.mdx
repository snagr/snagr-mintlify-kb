---
title: "How to batch edit User(s) Role / Enabled?"
---

Something you need to know before batch edits the user(s) role / enabled:

- [<img src="/images/direct/1556879641235-electric-light-bulb_1f4a1.png" alt="electric light bulb 1f4a1" width="28" /> How to set permissions? (Issues)](/en/set-up-project/accounts-and-permissions-project-level/how-to-set-permissions-issues)
- <img src="/images/direct/1556879590136-exclamation-mark.png" alt="exclamation mark" width="26" /> User role will directly affect the inspection & form permission of the user, you should never update the user role after updated inspection/form permission.
- <img src="/images/direct/1556878137919-1556878137919.png" alt="1556878137919" width="26" /> What's **Enabled?** If you would like the user to access the system, check enabled. If you would not like the user to have access anymore, uncheck the box. They would not be able to login to the system then. Note a user can be disabled but cannot be deleted. This is to protect the project data such that if a user has created any issues or forms previously the record always remain.

<img src="/images/direct/1556879917837-Admin_Website.001.jpeg" alt="Admin Website.001" />

"Project Administration" &gt; "Users" &gt; "Batch Edit Users"

<img src="/images/direct/1556880034949-Admin_Website.002.jpeg" alt="Admin Website.002" />

Select User(s) to edit

<img src="/images/direct/1556880358789-Admin_Website.003.jpeg" alt="Admin Website.003" />

You can select multiple users by the search for a keyword.

<img src="/images/direct/1556880394334-Admin_Website.004.jpeg" alt="Admin Website.004" />

Check the "Edit User(s) Roles" box to edit user(s) role.

<img src="/images/direct/1556880416064-Admin_Website.005.jpeg" alt="Admin Website.005" />

Check the "Enable / Disable selected User(s)?" box to Enable/Disable user(s).

<img src="/images/direct/1556880431878-Admin_Website.006.jpeg" alt="Admin Website.006" />

"Save"!!!
