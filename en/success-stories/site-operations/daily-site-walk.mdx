**What were the challenges?**

1. Searching activity details from site diaries (papers or excel files) is extremely time consuming and tedious yet it is often required when processing claims from contractors
2. Lack of visualisations to site diary reporting
3. Increased admin workload as site diaries need to be compiled from various teams / contractors each day

This is a site diary report completed each day. As time goes by, the pile stacks up / more Excel files are added to the site diary folder.

**How did SnagR help?**

1. Digitalise site diary submissions
2. Utilise data captured by engineers each day to reporting needs
3. Search for activity details by keyword search, submission date, location, etc.

Process **A****fter** Implementing SnagR

The daily site [form is digitalised](/en/set-up-project/forms-company-level/how-do-i-digitalise-a-form) on SnagR. As soon as the engineers fill in the form on mobile app, the data feeds into an automated report that can be printed or exported as PDF in a click.

**What is required to set this up?**

1. [Site diary form](/en/set-up-project/forms-company-level/how-do-i-digitalise-a-form) in PDF, png or jpeg
2. List of [users](/en/set-up-project/accounts-and-permissions-project-level/how-to-add-users-to-project) and [contractors](/en/set-up-project/accounts-and-permissions-project-level/how-to-add-contractors-to-project) who will have to submit site diary
