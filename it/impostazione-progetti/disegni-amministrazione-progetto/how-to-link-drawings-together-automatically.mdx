**Come generare piani di navigazione per tutti i disegni di Progetto**

I questo esempio generiamo piani di navigazione per u progetto residenziale con piu' appartamenti per piano. I Set Disegni son creati per piano: es 1F, 2F etc. I Disegni all' interno del Set sono uno per ogni unita' (es 5A, 5B, 5C etc per appartamenti al quinto piano)

Vediamo come SnagR genera piani di navigazione automaticamente:

<img src="/images/uploads/129348-Admin_Website.013.jpeg" alt="Admin Website.013" />

Procedura

<img src="/images/uploads/129345-Admin_Website.010.jpeg" alt="Admin Website.010" />

Generiamo nel primo tab i piani di navigazione per **tutto il progetto**

<img src="/images/uploads/129346-Admin_Website.011.jpeg" alt="Admin Website.011" />

Prima di avviare la procedura automatica create un Set Disegni "Navigazione " dove SnagR salvera' i piani di navigazione. Confermate a SnagR dove salvare i piani

**Se vogliamo generare prospetti di navigazione solo per un Set di Disegni?**

Nel secondo tab della pagina potete generare piani di navigazione solo per un Set Disegni.

<img src="/images/uploads/129347-Admin_Website.012.jpeg" alt="Admin Website.012" />

In questo caso scegliete dove salvare i piani di navigazione (secondo menu a tendina in basso) e indicate il Set Disegni per cui volete che SnagR generi il piano navigazione (primo menu a tendina)
