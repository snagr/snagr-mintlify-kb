---
title: "Creazione Set Disegni"
---

Un Set Disegni e' una cartella che contiene disegni relativi ad un progetto, permette di:

1. Cercare disegni in modo efficiente e raggruppare disegni per attivita'-area cantiere-tipologia
2. Filtrare le informazioni riguardanti Difetti ed Ispezioni

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **applicazione web**

Vai a **Amministrazione Progetto&gt; Disegni**

Inserisci nome Set Disegni &gt; Clicca **Aggiungi Set Disegni**

<img src="/images/uploads/129320-Website_Issue_Mode.001.jpeg" alt="Website Issue Mode.001" />

**_Esempio_**

In un progetto creiamo un Set Disegni per ogni piano

In questo modo possiamo rapidamente selezionare un Set Disegni e ottenere reportistica difetti o documenti per piano.
