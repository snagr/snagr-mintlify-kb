Funzione di Amministrazione Societa'

Log in **Area Amministrazione Societa'** in **Ispezioni Societa'** andate a **Fasi di Costruzione**.

Cliccate Importa Ispezione Fasi di Costruzione.

Indicate nome ed iniziali dell' Ispezione

Scaricate il template Excel per creare le Fasi di Costruzione.

Come compilare il file Excel per l' importazione

Nella colonna A indichiamo l' attivita': ad esempio Scavi Preparazione Fondazione

Nella colonna B l' attivita' generale o specialita', ad esempio Scavi

Nella colonna C i giorni all' inizio dell' attivita', solitamente valore 0 per la prima attivita della lista. Per la seconda attivita' della lista nella colonna C indicheremo 0+ x giorni necessari a finire la prima attivita', e cosi' di seguito.

Per attivita' sequenziali dobbiamo tener conto del loro susseguirsi quando indichiamo la data d' inizio di ogni attivita'.

Nella colonna D durata dell' attivita', ad esempio 2 giorni.

Nella colonna E indichiamo un Modello di Ispezione. Se a conclusione dell' attivita' sara' necessario compilare un Documento di Ispezione l' attivita' non sara' conclusa fino ad avvenuta compilazione e chiusura dell' ispezione.

Una volta completata la compilazione salvate il file.

Tornate all' applicazione web SnagR ed importate il file.

La griglia di verifica mostrera' tutti i record del file Excel.

I record mostrati in verde saranno importati mentre quelli mostrati in rosso saranno da emendare.

Una volta importato il file tornerete alla pagina di creazione dell' Ispezione.

Se necessario in questa pagina potete modificare le Fasi. Nel caso vogliate riempire il file Excel e succesivamente importare cliccate su Visualizza.

Poi cliccate "Importa Nuova Fase di Costruzione".
