Quando sincronizzate collegate il vostro dispositivo mobile al server usando una connessione internet.

Per la raccolta dati sul campo non e' necessaria una connessione internet: i dati sono temporaneamente conservati sul vostro dispositivo. Quando una rete e' disponibile (wi fi del vostro ufficio) sincronizzate a costo zero. Quando sincronizzate i vostri dati sono trasferiti al server e diventano visibili per tutti.

<img src="/images/uploads/127042-Getting_Started.004.jpeg" alt="Getting Started.004" />

La sincronizzazione transferisce i dati dal vostro dispositivo al server e raccogliere dati aggiornati dal server al vostro dispositivo (rilevazione di vostri colleghi, riparazioni di sub appaltatori, etc.). Sincronizzate PRIMA di iniziare a lavorare in cantiere ed a FINE GIORNATA.

Questo processo vi assicurera' che ogni aspetto del progetto e' aggiornato nel vostro dispositivo mobile.
