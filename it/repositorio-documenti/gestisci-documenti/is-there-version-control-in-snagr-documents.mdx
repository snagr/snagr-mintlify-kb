SnagR tiene traccia di aggiornamenti nei documenti e Disegni utilizzati.

I Disegni per esempio possono essere aggiornati in modo semplice e veloce.

Nel **repositorio documenti** e' sempre possibile aggiornare un documento disponibile per consultazione ed inoltre verificare quale la versione dello stesso stiamo consultando.

Per ogni file esiste una cronistoria delle versioni utilizzata, come nel caso il file aggiornato abbia lo stesso nome del precedente; altrimenti i files possono essere rinominati e salvati in una cartella differente con nome differente, oppure i vecchi documenti possono essere raggruppati in una cartella "versioni precedenti"

Per aggiornare la versione di un file cliccare su **carica**.

<img src="/images/direct/1525768637048-Document_Website.001.jpeg" alt="Document Website.001" />

Caricate il file con drag and drop oppure con la finestra di selezione classica.  
<img src="/images/direct/1525755968318-Red_Flag_Emoji.png" alt="Red Flag Emoji" width="23" />Se il file ha nome differente da quello originale essi saranno entrambi nella stessa cartella come due entita' separate

<img src="/images/direct/1525768652880-Document_Website.002.jpeg" alt="Document Website.002" />

<img src="/images/direct/1525768695539-Document_Website.003.jpeg" alt="Document Website.003" />

Se i file hanno lo stesso nome cliccare sul file per aprire la finestra proprieta'.Clicca su **Vedi cronistoria** per i dettagli della storia del file.

<img src="/images/direct/1525768750162-Document_Website.004.jpeg" alt="Document Website.004" />

Le varie versioni dello stesso file sono disponibili per download con l' icona
