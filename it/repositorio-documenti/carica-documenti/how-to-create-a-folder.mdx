---
title: "Come creare una cartella nel Repositorio Documenti"
---

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="20" /> **applicazione web**

Nel Repositorio Documenti esiste una cartella creata di default con il nome Progetto. Possono essere create altre cartelle e sottocartelle a seconda delle necessita'.

Vai a **Repositorio Documenti** e clicca **Aggiungi** per aggiungere una cartella, indicate il nome cartella.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> E' possibile creare diverse gerarchie di sottocartelle.
