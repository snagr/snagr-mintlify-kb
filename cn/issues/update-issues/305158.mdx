在[缺陷创建](/zh-hant/issues/add-issues/280571)之後，牵涉到多方人员来修改，签署和关闭缺陷。这样让所有的有关人员参与其中就尤为重要。

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **移动设备**

当你尝试要关闭缺陷，你有如下几个选择：

**快速关闭**：改变缺陷状态，图钉的颜色也会随之改变。

**关闭并评论**：改变缺陷的状态，并附以照片或者评论，图钉的颜色也会随之改变。

除了只读用户，所有的SnagR用户和承包商都可以使用更新缺陷功能。

**如何**在网页版更新缺陷

你可以在缺陷总览或者查看图纸界面更新缺陷。

#### 缺陷总览

直接将缺陷拖动到你想要的目标栏中。

<img src="/images/direct/1523867722659-Website-Issue-Mode_Sim.016.jpeg" alt="Website Issue Mode Sim.016" />

<img src="/images/direct/1523867783380-Website-Issue-Mode_Sim.017.jpeg" alt="Website Issue Mode Sim.017" />

#### 查看图纸

点击关闭/修复来改变缺陷的状态。

<img src="/images/direct/1523867859664-Website-Issue-Mode_Sim.018.jpeg" alt="Website Issue Mode Sim.018" />

根据你在系统内所预设的权限，你会相应地看到按钮&lt;修复&gt;签收&gt;&lt;关闭&gt;。
