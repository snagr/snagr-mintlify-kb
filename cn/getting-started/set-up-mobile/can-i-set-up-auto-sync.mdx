---
title: "我可以设置自动同步么？"
---

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="20" /> **移动设备 - 只限 iOS**

自动同步是一把双刃剑。好处就是你的设备与你的服务器实时保持同步。你不必担心你会忘记同步你的项目。

但是，一旦你的设备进行了同步，只有管理员才可以删除已经同步的缺陷。
