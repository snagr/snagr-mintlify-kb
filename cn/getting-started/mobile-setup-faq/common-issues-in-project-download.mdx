<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="20" /> **Device**

These may be some error messages you see:

\1. "Incorrect username and password"

\2. "Checking Credentials" (taking forever to load)

**What's wrong?**

These are likely related to a mistaken URL input. Please be sure to have the correct URL.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> The URL should not end with a slash (/).

E.g., [http://demo40.snagr.com.hk/training/](http://demo40.snagr.com.hk/training/) will prompt an error. [http://demo40.snagr.com.hk/training](http://demo40.snagr.com.hk/training) is correct.

**Too much typing?**

To be sure you make no mistakes, pull up the QR code scanner so SnagR imports the info for you perfectly.

You will find the QR code scanner here:

<img src="/images/uploads/129319-Getting_Started_Device.003.jpeg" alt="Getting Started Device.003" />

Scan the QR code provided on the welcome email from SnagR, and your project URL and username should be in perfectly.

<img src="/images/uploads/129318-scan_qr_code.gif" alt="scan qr code" />

Simply type your password to proceed. You are good to go!
