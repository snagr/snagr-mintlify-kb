Standaard is er een map die genoemd is naar het project. Als je meer mappen wilt maken om documenten georganiseerd te houden, kan je het volgende doen:

Ga naar **Documenten Opslag**, klik op **Toevoegen** om een nieuwe map toe te voegen.
