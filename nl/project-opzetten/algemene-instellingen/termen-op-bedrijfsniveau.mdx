**Dit is een Bedrijfsniveau functionaliteit**

**Login op Bedrijfsniveau**

Klik op **Termen** in het linker menu

Hier geeft een raster alle termen aan die je optioneel kan gebruiken voor projecten. De termen kunnen aangepast worden naar eigen wens om zo beter bij een project te passen.

**Programma** is een selectie van termen om deze vervolgens snel aan een project te kunnen koppelen.

Wanneer je de per stad de projecten wilt opslaan, kan je bijvoorbeeld **Div1** veranderen in een stadsnaam.

Om de termen te wijzigen, klik je op het potloodicoon aan het einde van de rij

Verander de naam en druk op het blauwe vinkje om op te slaan of het rode stopteken om te annuleren,

Onder het raster kan je aangeven of je deze labels getoond wilt hebben bij het aanmaken van een nieuw project. Dit doe je door de regel **Toon Extra velden bij het aanmaken van een nieuw project** aan te vinken.

Je kan hier ook aangeven dat het niet mogelijk is gebruikers of aannemers vanuit het project zelf toe te voegen. Dit doe je door de regels **Toevoegen Gebruikers vanuit Project Uitschakelen** en/of **Toevoegen Aannemers vanuit Project Uitschakelen** aan te vinken.
