Wanneer een project is toegevoegd, wordt er ook wat informatie voor dat project toegevoegd. Je bent instaat om het meeste van deze informatie aan te passen nadat het project is aangemaakt.

Voorbeelden van informatie die aangepast kunnen worden zijn; Contractnummer, Standaard taal, Projectcontact informatie, Logo, Cliëntgebruiker instellingen, Notificaties tijd van versturen, etc...

Log in op het project

Ga naar **Project Administratie** in het menu

Klik op **Project Instellingen**

Hier kan je de algemene informatie van het project zien

Je kan de informatie die je wilt aanpassen.

Om de wijzigingen op te slaan druk je op **Bewerk Project Instellingen** onderaan op de pagina.
