Dit is een Bedrijfsniveau functionaliteit.

_Voor het aanmaken van een project checklijst voeg je op bedrijfsniveau alleen een naam voor de lijst toe, de rest voeg je toe in een project (deel 2)._

Klik op **Bedrijfsinspecties &gt; Project Checklijsten**.

Klik op **Maak Nieuwe Project Checklijst** om een nieuwe checklijst te maken en als je er al een hebt gemaakt en deze wilt bewerken, druk je op **Bewerk**.

Vul de naam in en de initialen voor de checklijst en klik op **Maak Project Checklijst**.

Om de checklijst te vullen, log je in op een project en lees je [hier](/nl/project-opzetten/checklijsten-en-schema-s-bedrijfsniveau/importeer-project-checklijsten-op-projectniveau) wat je moet doen.
