**Genereer navigatie koppelingen voor alle tekening sets.**

In dit voorbeeld is het een woonproject met meerdere eenheden op een verdieping. De tekening sets worden gecreëerd per verdieping, bijv. 5F, 6F, 7F en etc. Elke tekening set bestaan uit de unit lay-out, bijv. 5A, 5B, 5C, 5D en etc.

Je kan deze koppelingen automatisch laten genereren:

**Kies Navigatietekening Map** betekent dat een tekenset moet worden toegewezen om deze navigatietekeningen te plaatsen. Meestal wordt een tekenset met de naam Navigatie gemaakt om deze automatisch gegenereerde tekeningen op te slaan.

**Wat dacht je van alleen specifieke tekningen?**

In plaats van Auto-Genereer Alle Navigatie Plannnen, kies **Auto-genereer Enkele Tekeningmap Navigatieplan.**

<img src="/images/uploads/129347-Admin_Website.012.jpeg" alt="Admin Website.012" />

Eerst, kies de tekening waarvan je automatisch de navigatie van wilt instellen. Kies daarna waar je deze automatisch gegenereerde tekening wilt opslaan.
