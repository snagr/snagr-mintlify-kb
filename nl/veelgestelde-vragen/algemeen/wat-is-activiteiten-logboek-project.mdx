---
title: "Wat is Activiteiten logboek project?"
---

Activiteiten logboek project houdt alle basis wijzigingen van de gebruikers in het project bij.

**<img src="/images/direct/1553573690492-1553573690492.png" alt="1553573690492" width="26" />** **Wie** kunnen Activiteiten logboek project bekijken?

**Projectbeheerders** kunnen Activiteiten logboek project bekijken in de **Project Administratie.**

<img src="/images/direct/1557138717289-Admin_Website.001.jpeg" alt="Admin Website.001" />

Je kan een specifieke **gebruikersnaam** selecteren om de logs hiervan te bekijken

Of

selecteer een specifieke **Modes**:

\- Alles

\- Inspectie Mode (Kan soms leeg zijn)

\- Actiepunt Mode

\- Setup Mode

Daarnaast kan je ook nog filteren op de kolommen door op de **Kolomnaam** te klikken.
