<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="18" /> **App**

**Voordat je synchroniseerd,** kan je zelf aangemaakte actiepunten verwijderen.

**Nadat je hebt gesynchroniseerd,** heb je de hulp nodig van een beheerder om actiepunten te verwijderen.

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> Als je een actiepunt per ongeluk hebt aangemaakt, kan je hem verwijderen voordat er is gesynchroniseerd.
