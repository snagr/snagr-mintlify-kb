In sommige gevallen wil je meerdere foto's toevoegen aan een actiepunt. Het kan gaan om een cloose up foto of een aantal foto's vanuit verschillende hoeken.

Volg simpelweg de onderstaande stappen:

<img src="/images/uploads/127098-Issue_Mode_Device.009.jpeg" alt="Issue Mode Device.009" />

<img src="/images/uploads/127099-Issue_Mode_Device.010.jpeg" alt="Issue Mode Device.010" />

Nadat deze foto's zijn toegevoegd, kan je deze terugvinden door op **Toon Geschiedenis** te drukken.

<img src="/images/uploads/127101-Issue_Mode_Device.012.jpeg" alt="Issue Mode Device.012" />

<img src="/images/uploads/127102-Issue_Mode_Device.013.jpeg" alt="Issue Mode Device.013" />
