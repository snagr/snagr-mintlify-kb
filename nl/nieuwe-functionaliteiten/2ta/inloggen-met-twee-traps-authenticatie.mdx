Nadat de Twee-Traps-Authenticatie geactiveerd is, moeten gebruikers inloggen met 2 verschillende factoren:

Om in te loggen op de website zijn de 2 stappen:  
**1. Gebruikersgegevens**  
**2. Verificatie code gegeneerd door de Authenticatie App (bijvoorbeeld Google Authenticator)**.

Om in de app in te loggen zijn de 2 verschillende factoren:  
**1. Gebruikersgegevens**  
**2. Vergrendelingscode van het apparaat / Vingerscan / Gezichtsscan**

<img src="/images/uploads/123693-if_ic_tv_48px_352186.png" alt="if ic tv 48px 352186" width="26" /> **Website**

Vul de **Gebruikersnaam** en **Wachtwoord** in.

<img src="/images/direct/1547006777634-Admin_Website-login-.001.jpeg" alt="Admin Website (login).001" />

Open de Google Authenticator app of een andere TOTP (Time-based One-Time Password) ondersteunende app om de verificatie code te verkrijgen.

**Vul de 6 cijferige verifcatie code in.**

<img src="/images/direct/1547006798752-Admin_Website-login-.002.jpeg" alt="Admin Website (login).002" />

Je bent nu succesvol ingelogd.

<img src="/images/direct/1547006912577-Admin_Website-login-.003.jpeg" alt="Admin Website (login).003" />

<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="26" /> **Device**

Vul de **Gebruikersnaam** en **Wachtwoord** in.

<img src="/images/direct/1547007157426-Admin_Device-login-.001.jpeg" alt="Admin Device (login).001" />

Vul de **vergrendelingscode van het apparaat** in.

<img src="/images/uploads/127041-Red_Flag_Emoji.png" alt="Red Flag Emoji" width="26" /> Voor iOS apparaten (Apple), **moet** je de vergrendelingscode / vingerscan / gezichtsscan gebruiken **nadat** je de gebruikersnaam en wachtwoord hebt ingevoerd.

<img src="/images/uploads/127041-Red_Flag_Emoji.png" alt="Red Flag Emoji" width="26" /> Voor Android apparaten, de SnagR App laat je alleen inloggen op het project wanneer er een vergrendelingscode / vingerscan is ingesteld op het apparaat.

### Hints en tips

### Moet ik elke keer als ik inlog een QR code scannen met de ondersteunende TOTP app om een verificatie code te genereren?

Nee, de TOTP app onthoud de scan en genereert continu een nieuwe code. Je moet de app dus wel openen om deze code te achterhalen.

Klik hier om te zien hoe je 2TA activeert.

### Moet ik de 6 cijferige code onthouden?

Nee, de 6 cijferige code zal elke 30 seconden veranderen.

Klik [hier](/nl/project-opzetten/accounts-en-rechten-projectniveau/hoe-reset-je-de-twee-staps-authenticatie-sleutel) om te leren hoe.
