<img src="/images/uploads/123669-if_icons_mobile_1564515.png" alt="if icons mobile 1564515" width="20" /> **App**

<iframe src="https://player.vimeo.com/video/139679318" width="100%" height="400" frameBorder="0" allow="autoplay; fullscreen; picture-in-picture" allowFullScreen></iframe>

Om te beginnen, installeer je SnagR <img src="/images/uploads/120714-SnagR_app.png" alt="SnagR app" width="16" /> via de App Store of Play Store.

Om een project toe te voegen, heb je **internet verbinding** nodig. Je hebt een project en een account nodig om het project te kunnen downloaden.

<img src="/images/uploads/126896-Test.001.jpeg" alt="Test.001" />

<img src="/images/uploads/126897-Test.002.jpeg" alt="Test.002" />

<img src="/images/uploads/127505-sparkles.png" alt="sparkles" width="20" /> Waar is de QR code voor?

Scan de QR code die in de welkomstmail staat. Hierdoor word **automatisch de project URL en gebruikersnaam ingevuld**. Vul alleen je wachtwoord nog in om door te gaan.

<img src="/images/uploads/126898-Test.003.jpeg" alt="Test.003" />

Je bent er helemaal klaar voor! Klik op Naar Tekeningen en ga van start.
